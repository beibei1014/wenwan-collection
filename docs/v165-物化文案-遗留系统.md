| ① | **称「它 / 这串 / 珠子 / 串儿」** | 沁灵是人 → 用 `ta / 他 / 她 / 名字`；实物珠串才说「这串 / 那一串」 |

| ③ | **保养术语当人格** | 「把我盘到挂瓷」「你盘我的手法」 |
| ④ | **「盘玩 / 挂瓷 / 包浆」当身体状况** | 「身上亮 / 比昨天圆 / 我身上也凉一点」 |
