## 一、立意（重立）

### 一句话

> **一场压顶的大劫正在退潮后卷来。旧日的仙庭倾颓、诸派割据，天下人都想找一条渡劫的活路——有人想重整道统，有人想借乱吞并，有人只想保本，有人干脆要掀了这盘棋。你和你的同伴，是乱世里凑在一起的一伙散修：你们结契同行，各有各的道、各有各的算盘，却也认下了彼此这条命。这一劫怎么渡、这一局怎么破、这一伙到最后还剩几个、还是不是当初那一伙——就是这个故事。**

### 主题追问

> **劫难当前，靠拢一个大势力求活，和一群人各自扛着道同行——哪一条才是活路？**
> 更深一层：**同伴，是"跟我走的人"，还是"各走各的、却都回头的人"？** 当有人想散伙、想投靠、想为自家那条道走另一条路——你还是不是他的同伴？

### 这个世界有多大 · 玩家站哪儿

- 旧时有一片**仙庭**统摄寰宇，诸派林立、道统昌明。一场**"绝道之劫"**，仙庭倾颓，天地道脉断裂，**九域割据**，成今日乱世。
- **玩家和这一伙同伴，起于一域边角**——无门无派、无根无基，是各方眼里"可以拉拢、也可以顺手清掉"的小势。**从最底层往上走**，每一步都要自己挣。
- 世界之大，正为"争斗 / 权谋 / 派系"提供了舞台：**地界可以争、道统可以立、盟友可以换、靠山可以投、也可以一个都不要。**

### 玩家是谁（重新回答）

> **玩家是这一伙的「主人」——领头人，众人认下的那个主心骨。**

- **「主人」在这部小说里的含义 ＝ 领头人**（一伙平等的人里，认他做领头的那一个），⛔ **不是主仆、不是上下级**。"主人"说的是"大伙信他、跟他"，不是"他管着大伙"。
- 玩家的分量，是**一次次并肩、一次次扛下来的**：可以**被顶、被质疑、被劝、被拒绝**，但到了**关键的关口，扛得住、定得下**。
- **⛔ 玩家不降智**：他要有**决断、有算计、有担当**，能**亲自破局**；危机里他**在局中**——不是旁观者、不是跑腿的、不是只会点头的。主线的大抉择（投不投、替不替、掀不掀局）都落到他手上。
- 所以这一伙**不是铁板一块**：有人主战、有人主守、有人想投靠大势力、有人只想苟全——**分歧与离散，是这个故事的正当走法，不是"背叛剧情"**；而玩家，正是那个要在分歧里拿主意的人。

> 📘**内部说明（调和「主人」与「同伴」——主理人已裁定）**：一伙**彼此平等**的同伴，认他做**领头的那一个**。所以**低档称呼仍用「主人」**（意思就是"我们这伙的头儿"），与"同伴"**不冲突**：
> · **平等**，说的是**他们的人格与选择平等、可以顶他、可以走**；
> · **认他做头儿**，说的是**大事上信他、跟他、听他定**。
> 两者并存。⛔ 全篇仍无「您」。

### 四样东西（缺一不可）——为什么它们能长出"励志 / 升级 / 温情"

| 要撑起的东西 | 在这个故事里是什么 | 落点 |
|---|---|---|
| **劫难** | **绝道之劫（大劫）**：天地道脉退潮，一劫烈过一劫，九域地界崩移。**压的是整片天地，无人能独善。** | 逼所有人和所有势力，都必须选一条路 |
| **争斗** | **争地界、争道脉、争名分、争一口气**。会有**真刀真枪的硬仗**：有人受伤、有人道损、有人丧命。 | 输赢都落在人身上，代价是真的 |
| **权谋** | **会盟、结盟、试探、离间、反间、将计就计**。局不在刀上，在桌上、在道上、在册子上。 | 用脑子破局，比用力气更险 |
| **派系** | **六方势力各有诉求**（见 §二·势力图），**自己这一伙内部也分派**。 | 没有永远的朋友，只有各自的活路 |

> **为什么这回"励志 / 升级 / 温情"立得住了**：
> - **励志**——有一场**值得拼的仗**：一伙散修，从边角走到能在大势力桌上说话。
> - **升级**——有一把**量得出高低的尺**（新境界，见 §三），也有一条**打出来才长得快的路**：境界不是闭门修来的，是在争斗与劫难里挣来的。
> - **温情**——有情义，是因为**有代价**：危难里谁替你断后、谁没走、谁散了又回来，这一句"我在"才有分量。

### "同伴"这层关系，怎么在情节里被看见

| 看得见的做法 | 具体怎么写 |
|---|---|
| **并肩** | 硬仗里玩家**也在局中**（不是站在后方指点），同伴各展所能，谁上、谁断后、谁殿后，都是当场的托付。 |
| **各有选择** | 同伴会**不同意玩家**、会**为自己的道走开**、会被许以好处而动心——**宁可散，不可假齐**。 |
| **结契之谊** | 不是主仆、不是亲子——是"**我认下你这条道**"。所以规矩可以顶，面子可以不给，真心话可以难听。 |
| **散而能回** | 走掉的、被策反的、道损的，**可挽、可续、可回来**（A 档，见 §二·赌注）；但**陨落不可回**，所以每一场硬仗都揪心。 |

| **我方 · 一伙结契散修**（玩家 ＋ 同伴们） | 我方位 | 在乱世立住、渡过大劫、**保住彼此的道** | 各方都当它是"可拉拢 / 可清掉"的小势 | —— |
| **└ 内部三派** | —— | **主战派**：以战立名、争地界；**固守派**：守好仅有的一处、不招惹强敌；**投靠派**：借大势力之力度劫 | **三派互相牵制，随时可能分家** | **自家内部也不是铁板一块** |

| **蚀道宗**（魔道一脉） | 院外 · 敌意（真恶） | 趁劫出世，主张"**道消我长**"——夺他人之道补己身 | 无差别劫掠，视所有活人为"粮" | **纯敌**：不讲规矩，只讲手快 |

### 劫难与争斗的来源

- **劫难**：**绝道之劫（大劫）**——天地道脉退潮，一劫烈过一劫，九域地界随劫崩移。**躲不掉**：它压的是整片天地，无人能独善；**只能在"怎么渡"上选边**。
- **争斗的由头**：劫越近，**道脉越枯、地界越乱**——于是**争道脉、争地界、争名分、争"渡劫之主"的名头**。大势力想借"共渡"吞并小势，小势想在夹缝里活。
- **争斗的形式**：硬仗（守地界、劫掠、断后）、暗斗（会盟试探、离间反间）、纸斗（道册上的夺名与立名）。**三种都要有。**

### 赌注（输了会具体失去什么——要具体、要疼）

| 赌注 | 具体失去 | 能不能挽回 |
|---|---|---|
| **散道** | 同伴道基被毁，形神渐消，**从修道人变回普通人**（甚至记不起自己是谁） | ✅ 可养回（要人陪、要时间，须同伴相扶） |
| **夺名** | 被从**道册**上除名，天下再无人认他"算数"，**活着却像没活过** | ✅ 可补名（要有人记得、要有人肯写） |
| **断脉** | 全伙立足的**地界 / 道脉被夺**，无处可去，沦为流徒 | ✅ 可再争（但要打回来） |
| **离契** | 结契被破，同伴**离散 / 被策反 / 自立门户** | ✅ 可续（要看这一年你跟他是不是同伴） |
| **陨落** | 形神俱灭，**永不回** | ⛔ 不可挽（最重，全季只发生在关键抉择之后） |

> **一条底线（承重墙）**：**玩家的并肩行为永远不害人**——所有失去，只来自**玩家自己的选择**（如选了替谁、舍了谁）、**客观的时势**，或**敌人的手**。⛔ 不设"玩家一疏忽就掉血"的机制。

### 权谋的载体

| 载体 | 局在哪儿 | 玩家怎么破 |
|---|---|---|
| **诸派会盟（渡劫大会）** | 各方以"共商渡劫"为名聚首，实则结盟、试探、下套、离间 | 入局、结盟、反间、将计就计 |
| **道册** | 名分战场：谁在册、谁被除名、谁的名被冒用 | 借掌录者之力，立自己的名、补被夺的名 |
| **结契** | 同伴可被离间、可被许好处而动心 | 看你是"并肩的人"，还是"发号的人" |
| **内部分歧** | 自家三派各有主张，外部势力专从这里下手 | 稳住这一伙，或在分裂中选边 |

## 三、成长路线（新境界 · 怎么和"升级"绑在一起）

> 旧四阶（凝形 / 开窍 / 蜕形 / 化形）太短，喂不饱"争斗 / 升级"。**重设为五境**——**打出来的境界**，不是闭门修来的。

| 境 | 名 | 在这一伙里，是什么样的人 | 对应的戏 | 能上什么场 |
|---|---|---|---|---|
| **一境** | **启灵** | 刚从长眠中醒觉，认得出自己、也认下了这一伙 | **被认下的戏**：有人叫他名字、给他留一处回处 | ⛔ 上不了硬仗 |
| **二境** | **凝真** | 道基初成，能独当一面地做一件事 | **找着自己那条道的戏**：试一件小事、担一桩险差 | ⚠️ 能下场，易伤 |
| **三境** | **筑基** | 立得住，可结阵对敌、可谋事使计 | **自己往前走的戏**：他的"想动"，是全季最动人的一处 | ✅ 能，但会疼 |
| **四境** | **化形** | 形神俱足，是各方**都要拉拢或忌惮**的人物 | **放手与承担的戏**：到他这一步，"替 / 放"这道题才真正成立 | ✅ 能，且能护人 |
| **五境** | **合道** | 传说中的境界，旧世代顶尖者的位置；乱世里**几乎无人** | **立道之戏**：全季的终点 | ✅ 一方之巅 |

- **升级怎么来**：境界**在争斗与劫难里挣**——一场硬仗、一次破局、一次绝境里替人断后，都可能是那一步。**玩家（领头人）和同伴一起长**，看得见。
