## 〇、演出规格（沿用 v164m3 §〇 的四层，引擎据此建）

| 层 | 内容 | 数据写法 |
|---|---|---|
| **① 背景** | 随镜号切换的全屏底图 | `{ bg:"BG-xx" }` |
| **② 立绘 / 站位** | L（左）· C（中 · 最前 · 说话者）· R（右）· B（后排 · 缩小压暗） | `{ at:"L/C/R/B" }` |
| **③ 对话框** | 底部一条：角色名 + 台词 | `{ w:"sp", who:"…", ps:["…"], t:"…" }` |
| **④ 旁白** | 收紧、每行挂一次画面变化 | `{ w:"sys", bg:"…", t:"…" }` |

- ⛔ **不画玩家 / 家长**——第一人称，不出立绘。
- 说话者移到 C（最前），未说话者退 B（后排）。
- 玩家台词走 `{ w:"me", t:"…" }`；本三章玩家以**沉默 / 选择**为主，少直接台词。
- 人称一律用 **`{ta}`（他 / 她）** 或角色名，**⛔ 分镜区 0 处「它」**（系统随机性别，`{ta}` 是唯一安全写法，且避开物化雷）。
- 选项文案 **≤ 12 字**；每条选项挂一个 `flag` 标签，供交互设计师落数据。
