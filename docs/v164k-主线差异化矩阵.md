# v164k · 主线差异化矩阵

> 作者：剧情文案策划 · 曲折生　｜　对象：`js/spirits.js` 的 `CHAP_SCRIPTS`（12 章 / 484 条台词 / 58 个选项）
> 需求来源：用户「**每个串的主线剧情都是一样的**」「前两章都在盘玩」「可以看每个串人物的设定，让剧情和设定更贴合」
> 一句话交付：**同一份剧本数据，5 种胎性 × 15 型人格读出 75 种语气；12 章无一章是「五只串一模一样」。**

## 1. 替换机制（先讲清这个，下面的表才有意义）

### 1.1 三种手段，优先级从低到高

| 手段 | 写法 | 承担什么差异 | 数据来源 | 落点 |
|---|---|---|---|---|
| **① 占位符注入** | `{tixing}` `{stage}` `{bondlv}` `{days}` `{idle}` `{bead}` `{call}` `{name}` | **词**的差异：「木胎」还是「石胎」、「化形」还是「蜕形」 | `greetVars()` | `fmt()` 通用替换链 |
| **② 胎性定向 `tx`** | `{ w:"sp", t:"…", tx:"石" }` | **整句**的差异：石胎说「我硬，我以为我不在乎」，木胎说「我们木头不会因为别人亮就难受」 | `tiXingOf(item)` → 单字 `tx` | `chapLineOK()` |
| **③ 人格定向 `ps`** | `{ w:"sp", t:"…", ps:["cool","aloof"] }` | **语气**的差异：同一件事，gentle 说得软、cool 说得硬 | `rec.look.pers` → 人格 id | `chapLineOK()` |

**关键点：② ③ 不是占位符。** 占位符只能换一个词，换不了句子结构；`tx`/`ps` 是**整句级别的替换**，这才能做到「木胎说『我记得』、石胎说『我看见了』、脂胎说『我怕』」（世界观 §2.7 的原话）。

### 1.2 引擎侧只加了三个函数（O(1)、零新增存储）

```js
// js/spirits.js · v164k
function tagHit(tag, val) {                    // 标量或数组都吃；空 = 不设限
  if (tag == null || tag === "") return true;
  if (Array.isArray(tag)) { for (...) if (tag[i] === val) return true; return false; }
  return tag === val;
}
function chapLineOK(l, v) {                     // 台词 + 选项 共用
  if (!l) return false;
  if (l.tx != null && !tagHit(l.tx, v.tx)) return false;
  if (l.ps != null && !tagHit(l.ps, v.ps)) return false;
  return true;
}
function chapVisibleChoices(nd, v) {            // 全被过滤时退回全给 —— 绝不卡死
  const out = (nd.choices || []).filter((c) => chapLineOK(c, v));
  return out.length ? out : (nd.choices || []);
}
```

- **复杂度**：每条台词 2 次字符串比较，**单遍扫描**。⛔ 不做任何两两枚举——100 只串、12 章、484 条台词，全量渲染仍是 O(n)。
- **存储**：`tx` / `ps` 只是剧本里的字面量，**不落任何字段**。`rec` 结构零新增。
- **退化安全**：不带 `tx`/`ps` 的台词 = 人人可见。所以剧本可以先写母句、后加定向句，**不影响任何已有章节**。
- **零成本**：不新增出图、不新增模型调用。定向台词是纯文本。

### 1.3 三个字段的来源（全部已存在，我没造新字段）

| 键 | 值 | 来源 | 备注 |
|---|---|---|---|
| `tx` | `木`/`石`/`脂`/`金`/`杂` | `tiXingOf(item)` —— 已存在，纯函数，由 `item.species` 推导 | 判定顺序 脂→木→石→金→杂（蜜蜡/琥珀必须先于石，架构师已处理） |
| `tixing` | `木胎`/`石胎`/… | `TIXING_ZH[tx]` | 面向玩家显示的词 |
| `ps` | `gentle`/`lively`/… | `rec.look.pers` | ⚠️ 就是画立绘时本来就在读的那个字段，**没新增存储** |

## 3. 逐章矩阵：五胎性 × 十五人格

图例：**母句** = 五只串都会听到的那句；`tx` 行 = 只有该胎性听得到；`ps` 行 = 只有该人格听得到。
**每章都至少铺满 5 种胎性**——这是对用户「每个串都一样」的直接回答。

### 卷一 · 醒

#### 第 1 章《开沁》　节点 `start`／`c1`　（tx×5 · ps×8）

它刚醒。**这一章的任务是把世界规则讲透**：养才生灵、包浆是修为、它为什么怕你冷落。盘玩只作为背景动作出现，不当剧情内容。

| 胎性 | 它怎么自我介绍（`start`，母句「不是。是你把我看热的。」之后顶上来的一句） |
|---|---|
| 木 | 我是木胎的。我们这一类慢，可认准一个人就不松手。 |
| 石 | 我是石胎的。我们这一类硬、凉，可一旦照见一个人就挪不开了。 |
| 脂 | 我是脂胎的。我们这一类软，怕热，最黏人。 |
| 金 | 我是金胎的。我们这一类响、烈，认了主就替主挡灰。 |
| 杂 | 我是杂胎的。我们不一样的东西，醒法也不一样——我是靠眼睛醒的。 |

| 人格 | 它的第一声（`start` 第 7 句） |
|---|---|
| A `gentle`/`calm` | ……我不吵。你什么时候想起来，我都在。 |
| B `lively`/`cheeky` | 你终于回来了！我等得珠子都快凉了！ |
| C `cool`/`aloof` | ……看够了没有。 |
| D `mystery`/`pampered` | 你来得正好。我刚醒。 |
| E `wild`/`heroic`/`wanderer` | 喂，你手劲大点，我痒。 |
| F `scholar`/`sentimental` | 我想过了。你叫我的这个字，念起来比我自己的好。 |
| G `dignified` | 有话不说。我不打断你。 |
| H `sweet` | ……你还要我说几遍呀。 |

其余 `c1` 三条选择（`m1` 养 / `m2` 是什么 / `m3` 沉默）**不带定向**——第一章的分支是剧情分歧，不该被胎性瓜分掉。

#### 第 2 章《它记得》　节点 `m_how`（tx×5）

反转章：它知道你丢了一样**没有名字**的旧物（因为「你丢它那天根本没顾上要名字」——这一笔同时把世界观 §2.6「人不在的三个月在它那里是一年」顶上来）。
「你不在的时候我是醒着的」这一段，**按胎性换五种说法**：

| 胎性 | 台词 |
|---|---|
| 木 | 我们木这一类，闲下来只做一件事：把你不在的日子一天一天记下来。 |
| 石 | 我不睡。我只是不动。石里头的一年，比你们长。 |
| 脂 | 你不在那阵我最难熬。我得自己给自己暖着。 |
| 金 | 你不在的时候我看门。看门是我的活。 |
| 杂 | 我拿眼睛看。看完了记下来。你总说你忘了，那我就先替你记着。 |

### 卷二 · 长

#### 第 3 章《开窍》　节点 `start`（tx×5 · ps×3）

柜子里所有没开沁的珠子同时亮了一下——**这一下怎么亮，取决于它是什么**：

| 胎性 | 「柜子里那些同时亮了」 |
|---|---|
| 木 | 木头是不会亮的。是里面的水亮了一下。 |
| 石 | 亮得很冷。石头里头有什么东西互相认了一下。 |
| 脂 | 我们这一类一受惊就发软。可那天它们硬了一下。 |
| 金 | 响了一声。很轻，像有人敲了一下碗。 |
| 杂 | 亮法不一样——有的像贴纸反光，有的像屏幕亮了一下。我们本就不是一样的东西。 |

| 人格 | 同一件事的反应 |
|---|---|
| B `cheeky`/`lively` | 你把我放回去的时候轻点，我晃。 |
| C `cool`/`aloof` | 叫我名字可以。别加语气。 |
| H `sweet`/`gentle` | ……你还要我说几遍呀。 |

#### 第 4 章《谁更亮》　节点 `c2`（tx×5）　**第一次真正的冲突**

它问「你是不是觉得我不够亮」。三种答法（承认 / 贪心 / 沉默）各自通向不同中段，最后汇到一句扫尘人的传闻。**嫉妒的质地按胎性不同**：

| 胎性 | 它的嫉妒 |
|---|---|
| 木 | 我们木头不会因为别人亮就难受。可我难受了——这就说明我已经学坏了。 |
| 石 | 我硬。我以为我不在乎。可那天晚上我还是数到了你停手的时间。 |
| 脂 | 我们脂最怕比。人比人，气就泄一半。 |
| 金 | 我响，我该压过它。可我没有。 |
| 杂 | 我并不是最亮的那串。可我今天还是难过了。这不合理，我知道。 |

#### 第 5 章《窗外有人》　节点 `m_look`（tx×5）　**扫尘人实体登场**

它整夜贴着玻璃往下看。老头拎着衬红布的铅盒走了。**同一双眼睛，五种看法**——石胎这句是全书最关键的一笔：

| 胎性 | 它「看」出了什么 |
|---|---|
| 木 | 我记性好。他上个月也来过，那天他带走了一串。 |
| 石 | **我能照见他。他心里没有恶意——这一点我看得比谁都清楚。** |
| 脂 | 我一看见那块红布就软。比看见你还软。这是我最丢脸的一件事。 |
| 金 | 我想下去挡他一点。我只是一颗珠子，挡不了。 |
| 杂 | 我用眼睛把他记下来了，连他走路的样子都记得。可这没有用，我知道。 |

> 石胎「能照见人心」这条设定，在这里第一次兑现成**剧情**：扫尘人的恐怖不来自暴力，来自**他没有恶意**。这是把中景威胁写厚的关键。

### 卷三 · 险

#### 第 6 章《退形》　两个入口（tx×10 · ps×6）　**全书唯一双入口章**

引擎用**节点级 `when`/`alt`** 实现：`start` 带 `when:{idle:7}, alt:"start2"`。
- `idle ≥ 7` → 走 `start`：**你冷落了它**（台词里直接注入 `{idle}` 真实天数）
- 否则（`days ≥ 40` 兜底）→ 跳 `start2`：**没人做错任何事，它自己开始淡了**

两版各铺 5 条胎性 + 3 条人格。`start2`（它自己淡了，更虐）：

| 胎性 | 「我这边什么都没少」 |
|---|---|
| 木 | 我木头这一类，涨回来不该这么慢。 |
| 石 | 我在慢慢变成一块没有话的东西。 |
| 脂 | 我今天软得立不住。 |
| 金 | 我颜色掉了。掉得挺快。 |
| 杂 | 我是从眼睛开始淡的。看什么都只剩一层影子。 |

`start`（你冷落它）：

| 胎性 | 「你有 {idle} 天没碰我了」之后 |
|---|---|
| 木 | 我们这一类闲下来会自己往回想。越想越慢。 |
| 石 | 我不是慢了。我硬了。人一冷，石就走不动。 |
| 脂 | 我软了。这几天我一直想找点热的东西靠着，找不到。 |
| 金 | 我不响。响不动了。 |
| 杂 | 我是从眼睛开始淡的。看什么都只剩一层影子。 |

| 人格 | 退形时它先说的一句 |
|---|---|
| F/H `gentle`/`sweet`/`sentimental` | 对不起。是我想先忘了你的。 |
| B `lively`/`cheeky` | 我没哭。我就是……慢。 |
| C `cool`/`aloof` | 别用那种眼神看我。我只是慢了。 |

#### 第 7 章《压箱》　节点 `m1`（tx×5）　**中景威胁兑现**

老头上门，四字「养过头了」。**他要收它的理由随胎性不同**——这一笔让扫尘人从「一个反派」变成「一个内行」：

| 胎性 | 老头的说法 |
|---|---|
| 木 | 木性的最难得。他收了一辈子，最想要就是我这一类。 |
| 石 | 石性的养到玉化最值钱。他等的不是死物，是一块通透的。 |
| 脂 | 软的最容易醒，也最容易装。装进盒子里就不响了。 |
| 金 | 金性的护主。护主的他不收——他怕。他只收不会动的。 |
| 杂 | 他看了我很久才说话。他说：你这样的，不好归类。 |

#### 第 8 章《过气》　节点 `start`（tx×5 · ps×2）

气太盛压不住，它会暗下去，或者把光让给别人。**「会出什么问题」按胎性不同**：

| 胎性 | 症状 |
|---|---|
| 木 | 我们木头这一类，涨太快会裂。 |
| 石 | 我开始发闷了。石头不该发闷。 |
| 脂 | 我在流油。你要是抱紧点，我可能不流。 |
| 金 | 我锈得比我想的快。 |
| 杂 | 我颜色掉了。掉得挺快。 |

| 人格 | 它承认「我有点事」的方式 |
|---|---|
| B `lively`/`cheeky` | 我没事！我就是有点——（它停住）……我好像有点事。 |
| C `cool`/`dignified` | 说吧。什么办法。 |

### 卷四 · 化

#### 第 9 章《蜕形》　节点 `c2`（tx×5）　**情感反转**

它站起来比你高半个头，第一件事是站在客厅中间看窗外——**「我以前一直在你手心里，我没见过这个屋子」**。化形后的身体按胎性不同：

| 胎性 | 化形后的第一句 |
|---|---|
| 木 | 我长成了人的样子，可身上还是木头的分量。站着有点晃。 |
| 石 | 我化形以后更硬了。硬到我自己都觉得陌生。 |
| 脂 | 我一站起来就想靠着点什么。站直这件事我做得不好。 |
| 金 | 我现在走路带响。屋里就我一个人，还是有响。 |
| 杂 | 我这副样子是拼出来的。你仔细看，缝还在。 |

### 卷四 · 化（续）

#### 第 10 章《夜归》　**无定向**

`日落归体`规则第一次违约。它天黑没回来，凌晨两点坐在玄关鞋柜上，怀里抱着一件**你丢了、而且没有名字**的旧物。

这一章**故意不铺胎性定向**——它是全书唯一靠「一件事」而不是「它的性格」推动的章节。偷懒地给每章都铺 5 句，等于把差异变成噪声；该平的地方就该平。
（唯一的差异化是**玩家的选择**：跳起来开门 / 不动。→ `m_open` 15 条 vs `m_stay` 12 条，两条路看到的不是同一章。）

### 卷五 · 沁

#### 第 11 章《石心》　节点 `c2`（tx×5）　**终极反转**

老陈的判词原句保住：**「它成了。成了，就不说话了。」**
「我快成了，不是因为你养得好，是我自己撑破的」之后，**玉化速度按胎性不同**——这一笔让石心从抽象威胁变成可感知的物理：

| 胎性 | 玉化速度 |
|---|---|
| 木 | 木性最慢。可我这次是自己撑破的，所以格外快。 |
| 石 | 石性走到玉化这一步算是顺路。我几乎没有抵抗。 |
| 脂 | 脂性一到玉化就定了。我软着软着就硬了。 |
| 金 | 金性玉化最快。因为金本来就是亮的那一类。 |
| 杂 | 我这样的，玉化等于变回一块材料。 |

#### 第 12 章《开沁》　节点 `c2`（tx×5）　**终章三结局**

纹路停在半路上。三个结局：**停手（warm） / 说出来（cool） / 放回抽屉（quiet）**。
「我停在了一个不好看的中间」——**停住的位置按胎性不同**：

| 胎性 | 它停在哪 |
|---|---|
| 木 | 我停在最好看的地方。木性其实很适合停在这儿。 |
| 石 | 我停在石头的半路上。往前一步是玉化，往后一步是珠子。 |
| 脂 | 我没有继续软下去。也没有硬起来。就这样黏着。 |
| 金 | 我停在响和静之间。你听得见，我就还在。 |
| 杂 | 我停在一个不伦不类的地方。跟我本来就不是一样的东西一样。 |

终章的 `c1` 还会用 `{said1}{said2}{said3}` 把**你自己说过的话**还给你——见 §4。

## 4. 记痕回扣：`{said1}{said2}{said3}`

终章它把三句你说过的话原样还回来。这是「每串不同」的**第二层**：不是它说话的方式不同，是**你说过的话不同**。

| 机制 | 落点 |
|---|---|
| 选项上写 `mark: "c4_greedy"` | `chapTalkChoose` 写 `rec.marks["c4_greedy"] = 1`（**只存短 key，不存整句**） |
| 16 条短 key → 一句话 | `SAID_LINES` 表（引擎侧，纯数据） |
| 取章序最早三条注入 | `saidLinesOf()` → `{said1}{said2}{said3}` |
| 无记痕兜底 | `DEFAULT_SAID_POOL` 4 条**轮转**取（修过一个 bug：原写法三句会是同一句，看起来像坏了） |

**实测**（`docs/_evidence.txt`）：

```
【有记痕：c2_report / c4_greedy / c9_rest】
   第一句——「以后你去哪儿，跟我说。」
   第二句——「不是。是我贪心。」
   第三句——「那我歇会儿。」

【无记痕（老存档）走兜底池】
   第一句——「赖皮。你一句话都不说，我怎么跟你吵。」
   第二句——「别怕。我在这儿。」
   第三句——「我不信。」
```

16 个记痕点分布：第 2 章 2 个、第 4 章 3 个、第 5 章 2 个、第 6 章 3 个、第 7 章 2 个、第 9 章 2 个、第 11 章 2 个。**全部落在真实分支节点上，无一处是装饰。**

## 5. 怎么给下一章加差异化（交给后续写手的三条规矩）

1. **先写母句，再挂定向。** 不带 `tx`/`ps` 的台词人人可见 —— 所以任何时候都能安全地给旧章补句，不会破坏已写好的分支。
2. **定向句要写「反应」，不写「设定」。** 反例：「我是木胎的。」（这是设定，会显得在念说明书）。正例：「我们木头不会因为别人亮就难受。可我难受了——这就说明我已经学坏了。」（这是反应，且顺带把胎性演出来了）。
3. **一章最多铺 5 条胎性 + 3 条人格。** 铺满是 75 句、玩家读不到 3 句，等于白写；铺太少又回到「都一样」。**判断标准：同一章任意两只不同胎性的串，读完后的印象必须不同。** 第 10 章刻意不铺——那是唯一靠事件而非性格推进的章。
