## 0. 范围 · 插入点 · 边界

### 0.1 覆盖组件（7 个）

| # | 组件 | 一句话 |
|---|---|---|
| ① | **羁绊条** | 八档进度 + 档名 + 到下一档距离 |
| ② | **心迹条** | 恋爱向 0–300 五档轨（含冻结态） |
| ③ | **照料三式** | 擦净 / 静坐 / 理线（各 1 次/日） |

| ⑦ | **Toast / 提示** | 复用现有 toast |

### 0.2 插入点（对齐 `app.js renderDetail`）

- **位置**：插在 `.detail-tags` 之后、既有信息区之前。
  ```js
  html += '<div class="detail-tags">' + tags + "</div>";
  // ← 心迹区插这里（html += renderHeartZone(it, rec);）
  ```
- **显示门槛**：**仅当该宝贝已唤醒为沁灵（存在对应 `rec`）时渲染**；否则整块不出现（不占位、不留空壳）。
- **内容列宽**：`.view` = `max-width:640px`，两侧 `padding:12px`；`.detail-body` 再 `padding:14px 4px`。
  → 心迹区内容宽 **W = min(视口, 640) − 32px**（桌面 ≈608px，常见手机 375 → ≈343px）。下表尺寸按此列宽给。

### 0.3 边界（不做的事）

- ⛔ 只做 UI：数值/门槛/状态一律**读接口 + 读集中配置**（`BOND_LEVELS` / `GIFT_CFG` / `HEART_CFG`），UI 内**不写死阈值**。
- ⛔ 不改故事、不改数值模型（承重墙见设计 §2.3）。
- ⛔ 颜色走 CSS 变量（本文新增 token 见 §2），不散落硬编码色值。

## 2. 色板（引用 token + 2 个新增）

> 基础 token 取自 `css/style.css`（浅色主题实测值），**暗色/主题皮肤自动跟随，⛔ 不写死**。新增 2 个 token 需写入 `:root`（集中配置）。

| 角色 | token | HEX（浅色） | 用途 | 对比度（白底实测/估算） |
|---|---|---|---|---|
| 主文本 | `--text` | `#2f2418` | 名称、档名、正文 | **≈15:1** ✅ |
| 次文本 | `--text-2` | `#8a7a68` | 计数、辅助小字 | ≈4.5:1 ⚠️（≤13px 勿承载关键信息） |
| 卡面 | `--card` | `#ffffff` | 区块/抽屉底 | — |
| 描边 | `--line` | `#e8e0d2` | 轨底、分隔、边框 | — |
| 羁绊条填充 | `--gold` | `#b8860b` | 羁绊轨、档点点亮 | **3.5:1**（图形，≥3:1 达标；⛔ 不作小字） |
| 命中/正向 | `--green` | `#2e7d32` | 「会喜欢这一类」标签 | **5.1:1** ✅ |
| 危险 | `--red` | `#c62828` | 受伤/警示（极少量） | ≈5.9:1 ✅ |
| 禁用 | `--gray` | `#9e9e9e` | 置灰项、置灰文字 | ≈2.6:1（**仅图形/非信息文本**） |
| **新增** 心迹轨 | `--heart` | **`#b0695f`**（胭脂） | 心迹条填充、心迹点缀 | **4.2:1**（图形 ✅；⛔ 不作小字） |
| **新增** 心迹文本 | `--heart-ink` | **`#8c4a44`**（绛） | 心迹档名/数值（文本用） | **≈6.6:1** ✅ |

**暗色主题**（`body[data-theme]` 分支，建议值，随皮肤微调）：`--heart: #c98f86`、`--heart-ink: #e0b0a6`；`--gold`/`--green` 用现有暗色值。

**新 token 落地**（架构师加，一行一个，集中放 `:root`）：
```css
:root { --heart: #b0695f; --heart-ink: #8c4a44; }
```

## 3. 组件规范（逐组件四态）

> 通用四态：**常态 / 悬停(hover，桌面) / 按下(active) / 禁用(disabled)**。触控项目以 `:active` 为主。
> 现有按下动画可复用 `skin.css` 的 `transform: scale(.955)`（`.btn:active`）。

### 3.1 羁绊条 `.bond-block`

**结构**：`头行(.bond-head: 档名+icon ─── 右:到下一档) + 轨(.bond-track: 8 刻度 + .bond-fill)`

**⚠️ 刻度非等距（承重）**：八档阈值 `0/12/30/55/90/140/200/280` **不是等差**。
- 刻度位置按 **各档段等宽** 铺（8 段，每段均分轨宽），段内再按该档 `pct` 填充 → 视觉上每档一格，公平可读。
- ⛔ **不要**按 `bond/280` 线性铺（会让前 7 档挤在 3% 宽度里）。

| 态 | 表现 |
|---|---|
| 常态 | 轨底 `--line`；填充 `--gold` 至当前段内 `pct`；已过档段整段点亮 |
| 满档 `isMax` | 整条 `--gold` 全亮 + 档名后加一个「满」微标；右侧显示「已到头」 |
| **涨动** | 本次 +N：填充 `width` 过渡到新值，同时**一道白色高光**自左向右扫过填充（500ms），尾端 3px 光点闪一下 |
| 升档提示 | 距下一档 ≤ 该档 10% 时，下一刻度做**脉冲**（opacity 0.4↔1，1.6s 循环），引导视线 |

**数据**：`Spirits.bondLevel(rec.bond)` → `{name, icon, next, nextIcon, pct, toNext, isMax}`。

### 3.2 心迹条 `.heart-track-block`

**显示条件**：`rec.heart > 0` **或** 恋爱线已开（`rec.loveLine === true`）；否则**整块不渲染**。

**结构**：`头行(.heart-head: 「心迹」+ 右:{value}/300) + 轨(.heart-track: 4 档点 + .heart-fill)`

- 5 档 = `Spirits.HEART_MARKS = [0,40,100,190,300]` → 轨上放 **4 个 8px 档点**（0 与 300 为两端）。
- 档名（若需）：**「心迹一…五」纯占位** —— 正式档名**待编剧（文成章）给**（本文不杜撰故事词）。
  - 🔴 **单一数据源纪律**：5 个档名必须来自**一个数组/映射**（如 `HEART_NAMES = ["心迹一", …]`，集中配置），再由它渲染到 DOM。
  - ⛔ **档名不得散落进 CSS 类名 / `data-*` 值 / DOM 文案硬编码**——否则定名回来要动一遍界面。CSS 只用**档位序号**（`.heart-lv-1…5`）定位，不嵌档名。
- 填充 `--heart`；数值文本 `--heart-ink`。

| 态 | 表现 |
|---|---|
| 常态 | 填充至 `value/300` 比例（心迹阈值本身较匀，可按线性铺） |
| **推进** | `width` 过渡 480ms + 尾端光点 120ms |
| 满档 | 全亮 + 档名后「满」微标 |
| **冻结**（30 天未互动） | 整条 **置灰**（`--gray`）+ 轨道末端一枚**暂停/冰晶图钉**；旁小字提示（文案待定，先占位「（搁着）」），⛔ 不写「掉分/惩罚」 |

**数据**：`Spirits.heartLevel(rec.heart)` → `{value, lv, lv1, max:300, atMax}`；冻结看 `rec.heartAt` 与 `HEART_CFG.FREEZE_DAYS`。

### 3.3 照料三式 `.care-row`

**三按钮等宽一行**：擦净 / 静坐 / 理线（各 1 次/日，合计 ≤ +6/日，走配置）。

| 态 | 表现 |
|---|---|
| 常态 | 底 `var(--card)`，边 `1px solid var(--line)`，图标 18 + 文字 13 |
| 悬停 | 边色转 `color-mix(--gold 40%)`，轻微上浮 1px |
| 按下 | `scale(.955)`（复用现有） |
| **已做**（今日已用过） | 置灰：图标/文字 `--gray`，按钮 `disabled`，右角一枚「✓」；点击无反应 |
| 完成反馈 | 点后按钮内**涟漪**扩散 360ms + 角标 ✓ 淡入 |

- 每键下方小字：未做「今日 +2」，已做「今日已做」（数值走配置，⛔ 不写「好感度」）。

### 3.4 「递一件给它」`.gift-cta`

| 元素 | 规范 |
|---|---|
| 主按钮 | 宽 100%，高 48，文字 **「递一件给它」**（⛔ 永不写「送礼」）；底 `var(--gold)`，字 `#fff` |
| 计数 | 右上小字「今日 {used}/{cap}」；**计数与 `globalGiven` 同源**：均读 `Spirits.giftGivenToday()`（玩家级 `ww_gift_log`），⛔ 不另算、不写死 |

| 态 | 表现 |
|---|---|
| 常态 | 可点 |
| 按下 | `scale(.98)` + 底加深 |
| **资格未达**（`bond < 相熟 30`） | **按钮保持可点**（不置灰），点后**不消耗、不扣物**，弹一句提示：「{ta}还没到接你东西的分上。」（设计 §3.3） |
| 全局用满（`day_global`） | 不拦按钮；进入抽屉后**全列表**置灰（唯一真正禁用，见 §3.5） |
| 本只今日已递（`day_per`） | 不拦按钮；进入抽屉后该项**可点**、标「今日第二件 · 心意减半」（见 §3.5） |

> **送参**：点选后调 `giveGift(gifts, rec, key, { dayKey, globalGiven })`，其中 `globalGiven = Spirits.giftGivenToday()`（`app.js` 详情页送礼 handler 读一次传入，保持 `giveGift` 纯函数）。

### 3.5 选礼抽屉 `.gift-sheet`（bottom sheet）

**结构**：`遮罩(.sheet-mask) + 面板(.gift-sheet: 头 + 列表)`

- 头：左标题「你手边有什么」+ 中「今日 {used}/{cap}」+ 右关闭 ×。
- 列表项 `.gift-item`：`[图标48] [名(15/600) / 描述(12, ≤2 行截断)] [右侧状态]`。
- **分色**（按 `cls`）：见 §6 占位色板。
- **排序（已定稿）**：可递 > 已收 > 库存 0；命中该沁灵偏好者**置顶 + 绿标**。

**7 种状态（按 `giveGift` 返回 `reason` 映射）**：

| reason | 列表项表现 | 可点 |
|---|---|---|
| `ok` | 正常；命中偏好时顶部挂绿标「{ta}会喜欢这一类」 | ✅ |
| `locked` | 置灰 + 锁图标 + 小字「还不到时候」 | ✖ |
| `dup` | 置灰 + 小字「{ta}已经收着呢」（判 `giftLog[key]` 有值） | ✖ |
| `day_per` | **可点** + 小字标「今日第二件 · 心意减半」（+2；命中偏好 **+3**） | ✅ |
| `day_global` | **唯一真正禁用**：全列表置灰不可点 + 顶部条「今天递得够多了。明天再说。」 | ✖ |
| `no_stock` | 名后「×0」置灰（`count===0`） | ✖ |
| `no_gift` | 未知 key → **不渲染该行**（防御） | — |

| 态 | 表现 |
|---|---|
| 展开 | 遮罩 `opacity 0→1`（200ms）；面板 `translateY(100%)→0`（260ms `--ease-out`） |
| 列表浮现 | 项 `160ms`、阶梯 `40ms` |
| 点可选件（`ok` / `day_per`） | 触发 `confirmModal` 二次确认（复用既有），确认后才调 `giveGift` |
| 关闭 | 反向动画 200ms；点遮罩 / 点 × 关闭 |

- **命中偏好**：`cls === Spirits.giftPrefOf(rec)` → 绿标 + 描述前缀「{ta}会喜欢这一类」；**未命中也要给反应**（+4），⛔ 无「送错白费」。
- **折半（已启用）**：**同一只**当天第 2 件 → ×0.5（+4→**+2**；命中偏好 +6→**+3**）；**不同串当天各送第 1 件不打折**。UI 落点：该项可点，状态字标「今日第二件 · 心意减半」，确认卡另加一行小字提示数值减半。

### 3.6 恋爱确认入口 `.lovecall-entry`

**门槛**：`stage >= 4 && 档 >= 7 && 玩家显式确认`（设计 §4.3）。

| 态 | 表现 |
|---|---|
| 未达 | **隐藏**（不占位、不置灰吊胃口）；或（备选）置灰 + 小字「还不到时候」——**建议隐藏** |
| 可达未确认 | 按钮「我想和{ta}更近一步」（`var(--card)` + 描边，非主按钮色） |
| 已确认 | 按钮收起，改显留空行 |
| 留空行 `.lovecall-blank` | 「从今天开始，叫我 ______。」——**一行手写留白**，虚线底线，⛔ 不出现「输入框」机制语；点击后原地变得可填写，句式为**一行填空** |

- 称呼显示行（档位决定，`callFor`）：`它现在叫你「{call}」`；`{call}` = `rec.lovecall` 优先，否则 `callFor(rec)` 结果。

### 3.7 Toast / 提示

- 复用现有 `.toast`（`z-index:300`, `fadeIn .2s`），**底部居中，距底 ≥ 96px**（避开底部导航）。
- 文案（来自设计，供参考）：资格未达「{ta}还没到接你东西的分上。」/ 置灰原因「{ta}已经收着呢」/ 已满「今天递得够多了。明天再说。」。
- 送出成功：**分型台词**（设计 §3.4 表）由文案给，UI 只负责呈现位置与节奏。

## 4. 字体与排版阶梯

| 层级 | 字号/字重 | 行高 | 用途 |
|---|---|---|---|
| 区块标题 | 15 / 700 | 1.4 | 「心迹」区小标题（可选） |
| 条头 | 14 / 600 | 1.4 | 羁绊 · 档名 / 心迹 |
| 正文 | 14 / 400 | 1.5 | 描述、说明 |
| 小字/数值 | 12 / 500 | 1.4 | 计数、「羁绊 +6」（**小字，非主体句**） |
| 微标 | 11 / 400 | 1.3 | 角标、×N |

- **字体栈**：沿用现有（`-apple-system, "PingFang SC", "HarmonyOS Sans SC", "Microsoft YaHei", sans-serif`），⛔ 不引入新字体。
- **单行字数上限**：抽屉描述 ≤ **18 字/行 × 2 行**（超出省略号；由文案侧拆句）。
- **数值跳动**：所有数字（羁绊/心迹/计数）用 `font-variant-numeric: tabular-nums`，防推进时宽度抖动。
- 文案口径：主体句写 {ta} 做了什么小事；数值只作小字。

## 5. 动效表

| 动效 | 时长 | 缓动 | 触发 |

| 心迹区入场 | 200ms | `--ease-out` | 详情页渲染，子块阶梯 60ms |
