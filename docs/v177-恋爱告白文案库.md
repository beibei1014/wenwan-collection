## 一、为什么重做 B / E（需求原点）

用户原话：

> 「拒绝了沁灵，什么契机下沁灵再次表白？表白的内容要不一样。还有我们沁灵有些可能性格会有重合，性格重合的沁灵告白的内容也应该不一样」

拆成两条硬要求：

1. **同型不同腔**：玩家可能同时养两只「温柔安静」。抽到不同变体时，读起来必须是两回事 —— 不能暴露模板。
2. **二告不能复读**：被婉拒过至少 7 天后沁灵自己再来，语气要更克制、必须提到那次被缓下来（不抱怨、不卖惨、不道德绑架），且是**另一件事、另一个场景**，不是首告的改写版。

对应到落地：B 列取文案的键是 **人格型 × 变体(0/1/2) × 轮次(1/2)**，变体由运行时稳定分配（建议按 `spiritId` 哈希取模 3），同一只沁灵终身不变。

## 二、口径（写之前先对齐）

1. **沁灵是人，不是物件。** 玩家是掌门 / 家长，沁灵是玩家养出的门派 / 家族 —— 彼此守护陪伴的家人温情。
2. **恋爱线规则**：可开后宫、多线并列互不排斥；门槛 stage ≥ 4 且羁绊档 ≥ 7；流程 = 玩家「挑明」→ **沁灵主动告白** → 玩家「应下」/「缓一缓」；婉拒不锁死。
3. **占位符只有两个，一律 ASCII**：`{call}`（这只沁灵对玩家的称呼：主人 / 你 / 昵称 / 专属称谓，运行时决定）、`{ta}`（这只沁灵的第三人称名字）。沁灵自称**写死「我」**。
4. **第二人称一律 `{call}`**（B / D / E 三列）。⛔ 不写裸「你」。
   - **例外（需拍板）**：A 列是**旁白**（第三人称叙述），句内「你」指玩家、不随称谓变化；C 列是**在问"该怎么叫"**，此时称谓尚未定，若写 `{call}` 会出现「我该怎么唤阿七？」的怪句，故 C 列保留裸「你」。→ 见第七节待确认 3。
5. **长度**：B 列 **30–60 字**；A / C / D / E 各 **1 句 ≤ 25 字**。
6. **后宫口径**：文案里⛔ 不许出现「唯一」「只有你」「只对你」「只叫你一个人」这类排他表述（会与其他线的文案打架）。上一版 cheeky 的 D 列「往后我只叫你一个人」已按此条改掉。
7. **计数口径**：中文字符 + 标点各计 1 字，占位符 `{call}` / `{ta}` 各计 1 字，破折号「——」计 2 字。常规字数 = 占位符按 1 计；**实落上限** = 把 `{call}` 按最长 12 字代入后的字数（两者都须 ≤ 60）。

## 六、写作说明（给续写者的方法）

### 6.1 15 型之间靠什么区分（沿用上一版 6 维）

顺序即优先级：**人称与自称 → 句式节奏 → 意象来源 → 承诺的形态 → 请求的姿态 → 留白量**。

- **人称与自称**：自称一律「我」，绝不变化 —— 变的是**怎么提对方**：温柔 / 沉稳 / 书卷型把对方写进句子当**共同主语**（一处过、一处担、一处读）；高冷 / 野性型把对方当**被评判对象**（旁人都不如、我认下的）；娇憨 / 富贵型把对方当**依靠**（好不好嘛、赖着）；侠气 / 江湖型把对方当**同行者**。
- **句式节奏**：短句 + 停顿（gentle / aloof，「就这些。」式收尾）；长驱直入（wanderer / heroic）；先冲后补（cool / lively，「别误会」「就这些」）；绕弯回扣（cheeky / mystery，末句才落正题）；设问收尾（sweet / scholar，「可好？」「可愿？」）。
- **意象来源**：日常烟火（柴米 / 风雨 / 院落）→ calm / gentle / sentimental；书本典故（点到为止，不掉书袋）→ scholar；景物代情（风 / 夜 / 落叶）→ aloof / sentimental；酒 / 路 / 山水 → wanderer；剑 / 诺 / 伤药 → heroic；衣角 / 脸红 / 汤 / 点心 → sweet；衣襟 / 媒礼 / 名分 / 账册 → dignified；梦 / 醒 → mystery；软垫 / 热茶 / 挪窝 → pampered；认人 / 屋檐 → wild。
- **承诺的形态**：gentle 承诺**陪伴**；calm 承诺**分担**；scholar 承诺**岁月**；wanderer 承诺**同行**；heroic 承诺**挡灾**；dignified 承诺**持家**；wild 承诺**不换人**；pampered 承诺**不走了**；sentimental 承诺**敢往后看**；cool **拒绝承认这是承诺**；aloof **只说"想在"**。
- **留白量**：gentle 舍不得多说、aloof 不习惯说、mystery 故意不说 —— 三者都话少，但少的原因不同。

### 6.2 🆕 同型的 3 个变体之间靠什么区分（本轮新增）

**同一个意思，三种切入方式。** 15 型共用同一组切入口，保证"同型不同腔"是**方法论**而非灵感：

| 变体 | 切入方式 | 句首长相 | 说的事 |
|---|---|---|---|
| **0** | **日子** | 「这些日子……」「日子一天天过……」「这些天……」 | 讲**此刻的状态**：我这一段日子是怎么过的、我心里是什么样 |
| **1** | **小事** | 「那日……」「前日……」「那回……」 + **一件具体的、玩家做过的小动作** | 讲**一个记忆锚点**：某个瞬间我记到如今（替我拢衣领 / 把伞斜过来 / 留最后一口汤……） |
| **2** | **往后** | 「往后的年岁 / 路 / 夜 / 书 / 梦……」 | 讲**承诺的时限**：往后的哪一段我要和你一处 |

配套的两条硬规矩：

1. **小事变体必须换道具（15/15 已做到）。** 同一只沁灵首告的"小事"和再告的"小事"必须是**两件不同的事**：gentle 拢衣领 → 挪座；lively 笑我笨 → 斜伞；cool 挡闲话 → 廊下等我；calm 挪担子 → 分活儿；mystery 梦话 → 打盹；cheeky 偷笑 → 留点心；wanderer 山路挡风 → 渡口系行囊；scholar 续灯 → 收书；aloof 关窗 → 挪伞；sweet 理头发 → 留汤；dignified 交家事 → 交账册；sentimental 扫落叶 → 挪花；heroic 裹伤 → 分伤药；pampered 挪软垫 → 端热茶；wild 伸手 → 屋檐下躲雨。**换道具 = 换场景**，玩家立刻知道"这是另一次"。
2. **往后变体刻意沿用同一个喻体（15/15，是有意为之）。** 变体 2 的"往后"用词就是**人格签名**（wanderer 的路、scholar 的书、mystery 的梦、aloof 的夜、heroic 的风雨、calm 的担子、pampered 的窝、cheeky 的位置……），首告与再告**不换喻体**——换了就不是这个人格了。变体 2 的"两次不重样"靠的是 **6.3 的语气降级**（承诺 → 状态、提问 → 不提问），不靠换词。
3. **日子变体换内容不换轴（15/15）。** 变体 0 首告说"我这一段日子是什么状态"，再告说"这些天日子照旧 + 给你台阶"——同一个"日子"轴，但**前半句的状态描述必须不同**（gentle「一来我就安心」→「照旧，你不必为难」）。

### 6.3 🆕 首告 → 再告的语气降级，具体降在四处

吃过一次软钉子，不能像没事人一样再冲一次。降级**必须同时落在这四处**，缺一处就会读成"复读"：

| 降在哪 | 首告 | 再告 | 例（gentle） |
|---|---|---|---|
| **① 先给对方台阶**（降的是"压迫感"） | 直接开口说心意 | 句首先说"你不必为难 / 日子照旧 / 没别的意思" | 首告「这些日子，{call}一来我就安心」→ 再告「这些日子照旧，{call}不必为难」 |
| **② 声明不讨答复**（降的是"提问"） | 可以提问、可以要一个点头（「可好？」「可愿？」「点个头就上路」） | **一律不提问**：明写「今日不讨答复 / 不催 / 只说一句 / 不必答」 | 首告「一处就好」→ 再告「今日我只想说一句：我还在」 |
| **③ 提那次被缓下来，且只提一句**（降的是"情绪"） | 无 | 固定用「那日说缓一缓，我记着」「上回那句缓一缓，我没忘」「那日让缓一缓，我应了」三种说法轮换；⛔ 不解释、不追问原因、不评价对错 | 「我记着」是**记着这件事**，不是记着这个伤 |
| **④ 收尾从"要答案"改成"我在"**（降的是"诉求"） | 收在承诺上（「往后风雨我挡在前」「至死不改」） | 收在**状态**上（「我还在」「我等得起」「我等得住」「我在呢」） | 首告「至死不改」→ 再告「这诺我仍守着，等{call}来取」 |

> **字数不降，降的是标点（实测）**：首告均 **35.0 字**，再告均 **37.0 字**——再告**更长**一点，多出来的字全花在"给你台阶"（①）和"提那次缓"（③）上；句数几乎不变（首告 2.04 句 / 再告 2.00 句）。真正降下来的是**句末语气**：
> - 首告**问号 6 处 / 感叹号 4 处**（sweet「好不好嘛？」、scholar「可好？」、dignified「可愿？」、heroic「若肯应」、lively「我说啦！」、wanderer「点个头就上路」都是**在要一个回应**）；
> - 再告**问号 0 处 / 感叹号 0 处**——一条都不问、一声都不喊。
>
> 所以"克制"的落点是：**把要答案改成不给压力**（再告 45 条中 33 条明写「不催 / 不讨 / 不逼 / 不必 / 慢慢 / 我还在」）。

### 6.4 续写检查法

1. 写完新人格，把它的 6 条 B 列**横着读一遍**：变体 0 必须出现「日子」且落在前半段（cool / wanderer / dignified 三型因人格开口方式是"先找补 / 先亮态度 / 先讲礼"，日子落在句中是被允许的）；变体 1 句首必须是「那日 / 那回 / 那夜」；变体 2 句首必须是「往后」。再告 3 条句首分别落在「这些天 / 前日 / 往后」上。
2. 再**竖着读一遍**：首告 3 条里不许出现"缓一缓"，再告 3 条里**每条都必须出现"缓一缓"**；首告可以有问号感叹号，再告**必须一个问号一个感叹号都没有**。
3. 把它的 B 列与 gentle、cool、heroic 三条并排读：**三行里任何两行能互换而不违和，就是失败，重写。**
4. 换道具检查：首告的"小事"与再告的"小事"若是同一件，重写。
