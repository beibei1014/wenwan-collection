## 一、口径（写之前先对齐的四件事）

1. **沁灵是人，不是物件。** 沁灵是玩家手上的文玩日久有灵、开了灵识后醒过来的**修行者**。玩家是掌门 / 家长，沁灵是玩家养出的门派 / 家族 —— 彼此守护陪伴的**家人温情**。
   ⛔ 已废弃旧设定，本文未采用：「石心化」「过度盘玩 = 杀它」「沁灵之间互相竞争」。
2. **恋爱线规则（v165b / v165c 用户裁定）**：可开后宫、多线并列互不排斥；门槛 stage ≥ 4 且羁绊档 ≥ 7（不锁天数、不锁章）；流程 = 玩家「挑明」→ **沁灵主动告白** → 玩家「应下」/「缓一缓」；**婉拒不锁死**，declined 后可再挑明；接受后玩家自填专属称谓，**填后不可改**，不同沁灵各叫各的。
3. **占位符只有两个，一律 ASCII**：`{call}`（这只沁灵对玩家的称呼：主人 / 你 / 昵称 / 专属称谓，运行时决定）、`{ta}`（这只沁灵的第三人称名字）。沁灵自称**写死「我」**。
4. **长度硬约束**：B 列告白语 **30–60 字**；A / C / D / E 各 **1 句 ≤ 25 字**。

## 四、写作说明（这 15 型是靠什么维度区分开的）

续写新人格时，按下面 6 个维度逐项定档，就能保证"换个型读起来就不一样"。顺序即优先级：**人称与自称 → 句式节奏 → 意象来源 → 承诺的形态 → 请求的姿态 → 留白量**。

### 1. 人称与自称（第一道分水岭）
自称**一律「我」**，绝不变化 —— 变化的是**怎么提对方**：
- 温柔 / 沉稳 / 书卷型：把对方写进句子当**共同主语**（「与你一处过」「和{call}一处担着」）→ 关系对等。
- 高冷 / 野性型：把对方当**被评判的对象**（「旁人都不如{call}」「{call}是我认下的人」）→ 位置在上方。
- 娇憨 / 富贵型：把对方当**依靠**（「可以吗？」「你得接着我」）→ 位置在下方。
- 侠气 / 江湖型：把对方当**同行者**（「咱们就上路」「与你同当」）。

### 2. 句式节奏（最快见效）
| 节奏 | 型 | 做法 |
|---|---|---|
| 短句 + 停顿 | gentle / aloof | 一句切两截，「就这些。」式收尾，绝不铺排 |
| 长驱直入 | wanderer / heroic | 一句到底，不给自己留退路 |
| 先冲后补 | cool / lively | 前半句冲，后半句找补（「别误会」「就这些」） |
| 绕弯回扣 | cheeky / mystery | 先绕（梦、猜、绕弯），末句才落到正题 |
| 设问收尾 | sweet / scholar | 句末抛一个软问句（「可以吗？」「你替我拿个主意？」） |

### 3. 意象来源（决定"古风"成色）
意象必须**从人格的日常里长出来**，不能通用：
- 日常烟火（柴米、风雨、院落）→ calm / gentle / sentimental
- 书本典故（诗经一句，点到为止，不掉书袋）→ scholar
- 景物代情（风、夜、远处、落叶）→ aloof / sentimental
- 酒 / 路 / 山水 → wanderer
- 剑 / 诺 / 风雨同当 → heroic
- 衣角 / 脸红 / 天天叫 → sweet
- 衣襟 / 媒礼 / 名分 → dignified
- 梦里梦外 / 醒与不醒 → mystery
- 伺候 / 赖着 / 挪位置 → pampered
- 规矩 / 认人 → wild

### 4. 承诺的形态（同一句"往后一处过"的 15 种说法）
- 温柔型承诺**陪伴**（守在身边）；沉稳型承诺**分担**（柴米风雨）；书卷型承诺**岁月**；
- 江湖型承诺**同行**；侠气型承诺**挡灾**；端方型承诺**持家**；
- 野性型承诺**不换人**；富贵型承诺**不走了**（赖下）；多愁型承诺**敢往后看**；
- 傲娇型**拒绝承认这是承诺**（「称谓罢了」）；清冷型**只说"想在"**。

### 5. 请求的姿态（C / E 两列最容易写成同一句）
- 上是**求**还是**给**：sweet 求（「叫什么呀？」）、scholar 请对方拿主意、dignified 立名分、wild 认人、aloof 只说"你说我听着"。
- 婉拒（E 列）统一走三步：**先接住（不急 / 无妨 / 随你）→ 给个理由或台阶 → 明确"我还在"**。
  ⛔ 绝不允许出现怨怼（「罢了」「算了」「不必了」）或关门的措辞 —— 婉拒不锁死是用户裁定，文案必须留门。

### 6. 留白量（区分 gentle / aloof / mystery 的关键）
三者都话少，但少的原因不同：gentle 是**舍不得多说**（话都省给对方）、aloof 是**不习惯说**（情绪推给景物）、mystery 是**故意不说**（半句悬着，等你来接）。

### 续写检查法
写完新人格，把它的 B 列和 gent**le**、cool、heroic 三条并排读一遍。**三行里任何两行能互换而不违和，就是失败，重写。**
