## 〇、设计立场（题眼：**开后宫 ≠ 无摩擦**）

用户**同时**要两件事：① **开后宫**（上一轮硬需求，仍要保留）② **要嫉妒、要修罗场**。

**正解**：机制上**多线仍可开（不锁死）** ＋ 叙事上**她们会察觉、会嫉妒、会闹出修罗场**。
⛔ **不是**退回「只能选一个」；✅ 而是把「**你能不能镇得住这一屋子人**」变成**真正的玩法与代价**。

| # | 公理 | 落到本系统 |
|---|---|---|
| 1 | ⛔ **可追溯** | 一切代价必须能回溯到**玩家自己的选择**（你同时招惹了多只 / 你没处理 / 你偏心）——**绝不是系统随机惩罚** |
| 2 | ⛔ **可挽回、不删关系** | 不许「关系归零」「再也回不来」这类硬抹除；每一只都有明确的**和解路径** |
| 3 | ⛔ **不占有 / 不控制 / 不物化** | 争的是**一口气、一份心意**，不是物主纠纷。沁灵是**人**，用 `{ta}`。⛔「你是我的」类占有向台词一律禁止 |

> **一句话给全体**：修罗场是「**这一年你到底把谁放在心上**」被摆到台面上的时刻——**刺激，但伤人不杀人**。

## 一、察觉机制（⛔ 全 deterministic，不许随机）

### 1.1 谁先察觉（★ v165e 按大纲 §10.5-二 对齐）

- **察觉靠「各自的观察通道」，不靠随机**。大纲 §10.5-二 定了先后顺序（照抄、可直接用）：

| 先看出来的顺序 | 人格型 | 看出什么（具体信号） |
|---|---|---|
| 第一 | `mystery` 知道点什么的 | 看**脚步**——你哪天早回、哪天晚回、进门先看谁 |
| 第二 | `scholar` 记账的 | 看**数**——谁多收一件、谁名字后画勾、谁没上桌 |
| 第三 | `gentle` 安静的 | 看**灯**——为谁留、为谁不留 |
| 第三 | `sweet` 最小的 | **凭直觉**——谁被多看一眼，第一个不高兴 |
| 随时（当场） | `lively` 最吵的 | 不看，**撞见**，撞见就当场说 |
| 最后（装没看见） | `dignified` 最老的 | 早知道，不说；太过了才压一句重话 |
| 不说，只走开 | `cool` 不爱说话的 | 什么也不看，只是**忽然不那么近** |

- **资格门槛（本文件定）= 档 ≥ 4**：低于档 4 的沁灵仍是「主人」视角，**听不懂其中的分量、不入场**——这既保真，又让**前 3 档保持纯家人向**（⛔ 不提前制造嫉妒）。
- **同档并列时**按人格型上表顺序（稳定可复现）；⛔ **不用 `Math.random`**。

### 1.2 三种触发条件（全部可判定）

| 代号 | 触发 | 谁能察觉 | 说明 |
|---|---|---|---|
| **D1 · 公开改口** | 某只跨入**档 4（同室，改称「你」）**或**档 7（相知，改称 `{nick}`）**，改口当日 | 所有**档 ≥ 4** 的**其他**沁灵 | 改口是公开信号，懂的人自然懂（v165 §7.1「改口本身就是一个情感进度标记」） |
| **D2 · 恋爱线露馅** | 某只 `rec.loveLine === true` 且 `rec.lovecall` 非空，告白剧情当日 | 所有**档 ≥ 5** 的**其他**沁灵 | 专属称谓一旦出口，藏不住 |
| **D3 · 当众偏爱** | 同一自然日内，玩家对 A **送礼 / 照料**，而 B 与 A **同屋**（`rec.roomId` 相同）或**夜话同场** | B（**档 ≥ 4**） | 眼见为实：你当着 B 的面对 A 好 |

- **敏感度门槛 = 档 4**：低于档 4 的沁灵仍是「主人」视角，**听不懂其中的分量、不入场**。这既保真，又让**前 3 档保持纯家人向**（⛔ 不提前制造嫉妒）。
- **⛔ 不设随机触发**：察觉只由「达成的条件」决定，玩家**永远能复盘自己做了什么**。

### 1.3 察觉写账（叙事名「心结」）
每次察觉：`rec.rivalSeen[rivalId] = dayKey`（记录是谁让它起了意），并给该只 `rec.jealousy += w`（权重见 §三；叙事层称这只软状态为「**心结**」，见大纲 §10.5-七）。去重：同一 `(self, rival)` 组合、同一触发代号，**7 天内只记一次**（防同一场景反复刷）。

## 二、嫉妒值模型（逐串 · `rec.jealousy`）

| 值域 | 带 | 名 | 玩家体感 | 机制效果 |
|---|---|---|---|---|
| 0 | 平 | 无事 | 照旧 | 无 |
| 1–2 | 闷 | 有点不对劲 | 它话少了 / 灯没点 | **无扣分**（只是演出） |
| 3–4 | 离心 | 明显闹别扭 | 会逼你表态 | 亲密度获取 **×0.75** |
| 5–6 | 冷战 | 家里冷了一半 | 事件张力最大 | 亲密度获取 **×0.5** ＋ **有下限回落**（§四.2）＋ 计入 `riftCount` |

- **加值权重**：单次察觉（D1/D2）**+1**；**当众偏爱（D3）+2**（更伤人）。
- **⛔ 不自动衰减**：不随时间自己掉。**只有玩家的处理（§四.3）才降**——这样「你哄不哄得回来」是你的选择，不是系统施舍。
- **硬顶 6**：⛔ 不无限累加（避免玩家一旦欠账就永远翻不了身）。
- **多线并列不受阻**：`rec.jealousy` 是**逐串独立**的，A 的嫉妒**不影响** B 的嫉妒，**也不阻断任何恋爱线的开启**。开后宫仍成立。

> **★ v165e · 三条叙事口径（编剧 2026-10-03 确认，⛔ 写剧本前必读）**
> 1. **⛔「心结」不做成可见的数字条**——任何让玩家看见「游戏是怎么做的」的字都删。世界观内**只准用行为表现**：灯没点、话变少、账上多一笔、从另一边走过去。顶多一个**氛围级隐性提示**，⛔ 不写「心结 +1」。
> 2. **档 4–6 的嫉妒＝「家人间的偏心不甘」，⛔ 不得提前写成恋爱向**（恋爱线门槛仍是 `stage ≥ 4` **且** 档 ≥ 7）。即：**早期吃的是「你偏了谁」的醋，晚期才是「你心里是不是我」的醋**。这条升级曲线要保留。
> 3. **摊牌 ≠ 万能解**：「处理得当清零」的**「得当」必须挂在剧情上**（有没有真正把话说开、有没有补上亏欠的那件事），⛔ **不是点一下就清零**；**表忠心的空话不算数**。判定说明见 §4.2 / §4.4。

## 三、表现分层（⛔ **严格按 §2.7 人物设定卡，同型不许混写**）

> 台词**由编剧最终写**；下表给**典型行为 + 台词方向**，是写作纪律，不是定稿。

### 3.1 主角团（八只，人格型不重）

| 人格型 | 角色 | 典型行为（嫉妒时） | 台词方向 | ⛔ 禁止写成 |
|---|---|---|---|---|
| `cool` 不爱说话的 | 想得多说得少 | **沉默与疏远**：不再主动开口，坐得远一点，三字以内 | 「三个。」／「嗯。」（问三句答一句） | ⛔ 不会大吵、不会解释自己 |
| `lively` 最吵的 | 动静最大心里最没底 | **当场炸**：抢话、重复、把话喊出来，越吵越没底 | 「我也要！我也要一个！」 | ⛔ 不会安静超过两句、不会记仇太久 |
| `gentle` 安静的 | 用做事代替说话 | **照旧做事，但不再留灯**：饭照做、地照扫，就是那盏灯不点了 | 「灯……今天忘了。」（其实没忘） | ⛔ 不会说重话、不会提要求 |
| `scholar` 记账的 | 一切要对得上账 | **翻账**：把数念出来，谁多谁少摆到明面 | 「这个月，你去了他那儿七回。我这儿三回。」 | ⛔ 不会抒情、不会大喊 |
| `mystery` 知道点什么的 | 什么都知道什么都不全说 | **袖手旁观点破**：半句话把事挑明，然后看你怎么办 | 「谁家的都行。你也是。」 | ⛔ 不会一口气说完、不会着急 |
| `sweet` 最小的 | 最小最怕被落下 | **直觉式难过**：不闹，先委屈，怕的是被丢下 | 「……我是不是又要一个人了。」 | ⛔ 不会讲道理、不会沉默太久 |
| `dignified` 最老的那只 | 家里的定盘星 | **说满话、讲道理**：像盖章一样把话定下来，不撒娇 | 「一屋人，要有一屋人的规矩。」 | ⛔ 不会犹豫、不会撒娇 |
| `cheeky` 嘴快的 | 嘴比脚快 | **当传声筒**：把话传来传去，越传越大 | 「你们听说了没有——」 | ⛔ 不会保密、不会低声 |

### 3.2 其他人格型（配角 / 邻居 / 门客，供群像修罗场用）

| 人格型 | 典型行为 | 台词方向 |
|---|---|---|
| `aloof` 只数脚步的 | 只报数，用数字表态 | 「三个。」（问什么都答这个） |
| `sentimental` 眼在数人的 | 轻笑、眼在数人、不点破 | 「你们家亮得很。」 |
| `heroic` 只执行的 | 直接、一两个字 | 「让开。」 |
| `wild` 坐不住的 | 短、直、报告式 | 「我去看过他那儿了。」 |
| `calm` 只记该记的 | 公事话、不寒暄 | 「随你。岁除要报数。」 |
| `pampered` 讲道理的 | 判词式、慢、稳 | 「一颗珠子不叫团。一屋子人，也不是一屋子。」 |
| `wanderer` 只认手快的 | 短、狠 | 「留下。」 |

> **差异化保证**：同为「闹」，`lively` 是**当场炸**、`cheeky` 是**传出去**、`sweet` 是**先委屈**——三者写法必须两样。这是用户上一轮特别强调的「同型不许混写」。
> **阶段改姿态**：凝形（4 头身）闹起来是「抱着东西不说话」；化形（成人）闹起来是「把话说到桌面上」。

## 四、修罗场事件与后果

### 4.1 事件触发与形态（★ v165e：按大纲 §10.5-四 扩为 5 种）

| 项 | 规则 |
|---|---|
| **触发** | 任一沁灵 `rec.jealousy ≥ 3`（离心），或 **D2 恋爱线露馅**当日 |
| **形态一 · 撞见** | 有人**当场看见**你把心分给了别人（`lively` 炸 / `cool` 走 / `sweet` 哭，同一件事三种反应） |
| **形态二 · 逼你表态** | 「你先给谁。」——把选择摊到桌面上（`dignified` / `scholar`） |
| **形态三 · 互相较劲** | 两只沁灵**彼此别苗头**，争一件事、争一个位置（`lively`×`scholar`；`cool` 冷处理） |
| **形态四 · 冷战** | 不出声、不应门、不上桌（`cool` / `gentle`）。**最安静，也最难哄** |
| **形态五 · 当众摊牌** | 把话一次说开，非要一个说法（`dignified` 摆规矩 / `scholar` 念账 / `mystery` 点破）；**全家人都在，你无路可退** |
| **去重** | `rec.riftLog[eventKey] = dayKey`；同一 `eventKey` 只在 `jealousy` 重新升档时再触发 |

### 4.2 玩家选项（四类 · ★ 叙事后果照抄大纲 §10.5-五，数值由本文件定）

| 选项 | 叙事后果（大纲 §10.5-五原话落点） | 数值效果（本文件定 · 可验算） | 走向 |
|---|---|---|---|
| **表态站边** | 被偏的**升**；其余各生心结（**`cool` / `gentle` 更重**）；当场不闹大，**隔阂从这一夜开始** | 被偏者 `jealousy -2`；其余各 `+1`（`cool`/`gentle` **`+2`**） | 易 HE，**难 GRAND** |
| **打圆场** | **一时平息**；两边都觉得「你没把我当回事」，**隐患攒着**，后期更易当众摊牌 | 相关只各 `-1`；**同一周已用 ≥2 次 → 减半失效** | 中间态，**攒到后期一次爆** |
| **回避** | **最省事，也最凉**——没人闹大，但**灯会一盏一盏地不点**；你不答，他们自己答 | 当日不降；**次日该只 `+1`** | 易滑向 **NE** |
| **公开摊牌** | **最重的一场**：要么**一次镇住**（大家认了，心结可解），要么**一次炸到底** | 全相关只 `-3`；**且满足「得当」条件（见下方判定）→ 直接清零**；否则相关只 `+1` | **要么最大团圆，要么最疼的 HE / NE** |

> ⛔ **「得当」的判定（★ v165e 编剧口径 · 挂剧情、不挂按钮）**：摊牌要清零，**必须同时满足**——
> ① 此前**无「回避」记录**（`riftAvoid` 为空）；② **剧情中确实做了「把话说开」或「补上那件亏欠的事」**（由剧本埋的可判定 flag 承接，如 `riftMended`）；③（可选）该只已回你一次话。
> ⛔ **只点一下「摊牌」按钮、或说了句表忠心的空话 → 不算数**，按「否则 +1」处理。**「得当」是行为，不是台词。**
> （编剧原话：「表忠心的空话不算数」；「圆场一周 ≥2 次失效」已被编剧肯定，保留。）

> ⛔ **没有「哪个选项最好」**——只有「你愿意担哪一种」（大纲 §10.5-五）。⛔ 任何选项都**不删关系、不清零心意、不锁恋爱线**。

### 4.3 后果（⛔ 可追溯 / 可挽回 / ⛔ 绝不致散）

| # | 后果 | 规则 | 追溯性 |
|---|---|---|---|
| 1 | **涨得慢** | 离心（3–4）亲密度获取 **×0.75**；冷战（5–6）**×0.5**（与 `HARM_CFG.BOND_SLOW` 同机制，可叠加取更低值） | 因为你同时招惹了多只 |
| 2 | **有下限的回落** | 冷战期，若玩家**连续 3 天「偏心 + 不处理」**，该只 `rec.bond -= 1/天`；**⛔ 下限硬卡「通意」(90) 绝不跌破** | 因为你**一直**不理它 |
| 3 | **岁除护盾受影响** | 掉档 → 滋养贡献**按表自动降**（§5.2：档6=64 → 档5=46），岁除缺口被顶大 | 客观后果，非惩罚 |
| 4 | **拖出大团圆** | 岁除判定时 `riftCount = #{jealousy ≥ 5}`；**`riftCount > JEALOUSY_CFG.GRAND_RIFT_MAX(1)` → 阻断 GRAND**（新增硬条件 `jointRift`） | 你让不止一只冷了心 |
| 5 | **拖出 HE** | 只要有一只掉到 **档 5（通意）**，`allHighBond`（要求 `bondLv ≥ 6`）为假 → **HE 也被阻断 → NE** | 同上 |
| 6 | ⛔ **绝不致散（BE）** | `scattered` 判定**只读 `stance` 与 `bondLv`**（v165 §5.9）；而回落**硬卡档 5（= `SHIELD_MIN`）**，**数学上不可能**让冷战把人推到 `bondLv < 5` | 🔴 **这是本系统的承重安全线** |
| 7 | **群像收束** | 岁除夜，冷战未和解的只**不站到榜下**（演出层）——但**人还在**（不 scattered），只是「今年没跟你并肩」 | 情绪落点，非数值惩罚 |

> **一句话给用户**：**修罗场能让这一屋人拿不到大团圆、能让人掉到 NE，但一个都带不走。**

### 4.4 挽回路径（明确、可达）

| 路径 | 效果 | 备注 |
|---|---|---|
| **主动去一趟**（见面 / 送礼 / 照料） | 该只 `jealousy -1`，并**停止回落** | 最轻的一步 |
| **递一件合它心的东西**（偏好命中） | `jealousy -1`（额外） | 复用送礼系统，不改规则 |
| **摊牌**（§4.2 公开选项） | `-3`，处理得当 → **清零** | 一次性资格 |
| **一次夜话**（和它单独说说话） | `-2` | 复用 `NIGHT_EVENTS` |
| **和解动作**（按人格，剧本写） | 清零并留一段专属回忆 | `cool` 是「什么都没说，把凳子挪回你身边」；`gentle` 是「灯，今晚我点」。⛔ 台词由编剧终稿 |

- **无时间压力锁**：⛔ 不设「必须在 N 天内和解否则永久损失」。**门一直开着**（对齐 v164l §6.1 第 7 档写法）。
- **好感度可回溯**：`rec.riftLog` 记录每一次事件的来龙去脉，玩家可在**回环点**重走该段（情分保留、选择清零，v165 §6.3）。

## 五、与既有系统的接口

| 接口 | 关系 | 说明 |
|---|---|---|
| **恋爱线（§十）** | 门槛**不变**：`stage ≥ 4 && 档 ≥ 7 && 玩家显式确认` | 嫉妒**不阻断**开启；是**关系内的张力**，不是开关锁。多线仍可并存 |
| **称呼（§七）** | 嫉妒**不改称呼档** | 冷战不会把「你」退回「主人」——⛔ 改口是**单向**的进度标记，⛔ 不许倒退（否则变成惩罚） |
| **`stage`（晋阶）** | **无关** | 嫉妒不写 `stageOf` 输入 |
| **岁除法力（§5.2/§5.9）** | **只影响滋养贡献（吃档位）** | 不写 `harmed`、不写 `scattered`；仅新增结局条件 `jointRift` |
| **`harmed`（§5.9）** | **正交**、可叠加 | `harmed` 是恶人造成；`jealousy` 是玩家自己造成。两者减速可叠（取更低系数） |
| **回环点（§六）** | `jealousy` / `rivalSeen` / `riftLog` **过回环点是否保留** → 见 §九-待定 | 情分保留原则下，建议**事件记录保留、当前 `jealousy` 清零**（那一年的账重记） |
| **开后宫** | **完全不冲突** | 逐串独立、无总量上限、无互斥、无「选 A 锁 B」 |

## 六、演算样例（可复算 · 对齐 v165 §5.9 / §九）

> 基准：12 只全 `stage 4`（化形，阶位贡献 **72**）、全员立场 **1.0**、须求 ch26 = **100**、`GRAND_MARGIN = −5`（缺口 ≤ −5 且无人受伤）、`HE` 要求 `allHighBond`（全员 `bondLv ≥ 6`）。

### 样例一 · 处理得好 → 仍是 **GRAND**
| 项 | 值 |
|---|---|
| 现状 | 8 只达档 7（滋养 86）→ 法力 = 72 + 86 = 158 → 缺口 = 100 − 158 = **−58 ≤ −5** ✅ |
| 事件 | D1 触发 2 只「闷」（jealousy 1–2），玩家当场**打圆场** → 全部 `−1` → 归 0 |
| 岁除判定 | `riftCount = 0 ≤ 1` ✅、`allHighBond` ✅、无 `harmed` ✅ |
| **结果** | **GRAND**（「齐了。」） |

### 样例二 · 处理不好 → 掉到 **NE**，⛔ **绝不会 BE**
| 项 | 值 |
|---|---|
| 现状 | 3 只达档 7（86），玩家偏心 A，冷落 B、C |
| 事件 | B、C 各触发 D3（当众偏爱）`+2` → 冷战（`jealousy ≥ 5`）；玩家**连续回避** |
| 回落 | B、C 连续 3 天被偏心且不处理 → 各 `bond −1/天`，从档 7（200）缓降；**硬卡档 5（90）** |
| 判定 | 1 只降到档 5 → `allHighBond = false` → **HE 阻断**；`riftCount = 2 > 1` → **GRAND 阻断** |
| **结果** | **NE**（「桌上多摆了一副碗筷。没有人动。」）——**人还在**，只是今年没并肩 |
| ⛔ 安全线 | `bondLv` 被卡在 5 = `SHIELD_MIN` → `anyScattered` **必为假** → **BE 不可能发生** ✅ |

### 样例三 · 多只冷战 + 有人带伤 → **HE**（不是 GRAND，也不是 NE）
| 项 | 值 |
|---|---|
| 现状 | 全员档 6（64）以上，`harmed = false` |
| 事件 | 2 只冷战但**在岁除前和解**（`jealousy` 清零）；另 1 只仍冷战 |
| 判定 | 和解的两只恢复档位；`riftCount = 1 ≤ 1` ✅ 不阻断 GRAND；但某只被掠客伤过未清（`harmed=true`）→ GRAND 增项「无人受伤」失败 |
| **结果** | **HE**（「身上有这一年被外人碰过的印子，可一个没落下。」） |

> 三例合起来证明：**修罗场能压档（GRAND→HE→NE），但压不到 BE**——与 A 档「可挽回」口径严丝合缝。

## 九、可解性自查

| 检查项 | 结论 |
|---|---|
| 是否存在**随机惩罚**？ | ✅ 无。察觉全 deterministic，代价全可回溯到玩家选择 |
| 修罗场是否可能**致散（BE）**？ | ✅ **数学不可能**。回落硬下限 = 档 5 = `SHIELD_MIN` → `bondLv ≥ 5` 恒成立 |

| 是否**永远无法挽回**？ | ✅ 无。和解路径明确，门一直开着，无时间压力锁 |
| 开后宫是否被削弱？ | ✅ 否。多线仍可并存，嫉妒只是**关系内张力** |
| 冷战是否可能**无限恶化**？ | ✅ 否。硬顶 6，回落有下限 |
| 「镇得住」是否真的可达成？ | ✅ 是。处理得当（表态/圆场/摊牌）可清零，样例一证明可达 GRAND |
