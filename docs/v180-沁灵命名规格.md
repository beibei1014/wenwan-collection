# v180 · 沁灵命名规格

> 撰写：小说剧情策划 · 文成章
> 依据：用户 2026-10-08 亲定——「**以后每个开沁的角色都要按照这个规格进行起名，不要那么随意地用珠子的名字来弄**」；规格由本团给 8 位 ＋ 江冽茗 ＋ 温茸之 取名时所用的规则**成文固化**。
> 用途：**今后每有一只新沁灵开沁，一律照此规格起名**；不再随手拿手串（珠子）的名字当人名用。
> 状态：**已成文 · 待你过目**。⛔ 未改 `js/`、未 commit、未 push。

---

## 〇、一句话原则

> **每一只沁灵，都要有一副"像人"的名字**：一个**姓名**、一个**字**、一句**人物诗**、一个**八字**——四件套齐备，且与它的**手串名意象**呼应（呼应，⛔ 不是照抄）。

---

## 一、四件套（缺一不可）

| 件 | 是什么 | 规格 | 例 |
|---|---|---|---|
| **姓名** | 正式姓名 | **三字 ＝ 姓（1）＋ 名（2）** | 陆临崖 · 楚柿遥 · 江冽茗 |
| **字** | 表字 | **两字**，古雅 | 瞻丹 · 秋晏 · 澄观 · 抱朴 |
| **人物诗** | 一句小诗，写其风骨与画面 | **一句**，以**逗号分句**（多为 2–3 分句） | 「剑过秋林，丹柿落肩，一笑便扫尽风尘。」 |
| **八字** | 八字典评 | **四字 ＋ 四字 ＝ 共 8 字** | 「丹柿随身，笑赴山河」 |

---

## 二、命名格式细则

1. **姓名**：一律 **姓 ＋ 两字名**（共 3 字）。姓与名合读，要像真人名，⛔ 不叠字、不口语化。
2. **字**：一律 **两字**，取古雅、可作表字者（如 承霖 / 秉衡 / 澄观 / 抱朴 / 守柔）。
3. **人物诗**：**一句**，用**逗号**分句（2–3 分句为宜）；写"风骨 ＋ 画面"，可带一点心绪，⛔ 不写大白话、不写成对联。
4. **八字**：**四字＋四字**（共 8 字），前半多写"形 / 物"，后半多写"心 / 志"。
5. **手串名（对应用）**：**只作对应关系**，⛔ **不进「姓名」栏**（遵 v175 用户裁定）。展示原手串的那个位置**保持不变**。

---

## 三、取材规则（名字从哪来）

> **姓名与人物诗，取自"手串名的意象"**（当代号用），但 **⛔ 不直接拿手串名当人名**。

- **做法**：把手串名的**意象**拆开，化成**姓 / 名 / 诗**里的字与画面——**取其神，不取其字面全串**。

**取字四步（照着做）**

1. **拆意象**：把手串名拆成 2–4 个"意象点"。例：**冰红茶 → 冰 / 茶 / 饮（斟、酌）/ 红（丹）/ 一点甜（甘）**。
2. **选字**：每个意象点，选 1 个**古雅的同义字**（冰→冽/寒/霜；茶→茗/瓯/盏；甜→甘/饴）。⛔ 不直接搬串名里的字当整名。
3. **定姓名**：**姓**任选（避开已用姓）＋ **名取两字**里带上"意象字"。例：冰→**冽**、茶→**茗** ⇒ **江冽茗**。
4. **配字 / 拟诗 / 拟八字**：**字**取两字古雅、扣其**风骨**（如"澄观"="看得透"）；**人物诗**用 2–3 分句写"意象 ＋ 画面"；**八字**前四字写"形 / 物"、后四字写"心 / 志"。

- **范例**：

| 手串名 | → 姓名 | 怎么取的 |
|---|---|---|
| 柿柿如意 | **楚柿遥** | 取"柿"入名，"如意"化作"遥"的从容 |
| 黄金算盘 | **萧景筹** | 取"算盘"的**筹**（算筹）入名，写"谋定得失" |
| 花间酒 | **苏栖盏** | 取"盏"（持盏）＋"栖"（花间栖身） |
| 冰红茶 | **江冽茗** | **冽**取"冰"、**茗**取"茶"（意象直落，全不从字面抄串名） |
| 粉黛熊 | **温茸之** | **茸**取"熊"的憨软、"之"收尾古朴，"温"取温润 |

- ⛔ **反例**：直接叫"冰红茶 / 粉黛熊 / 柿宝 / 金算盘"（把珠子名当人名）——**这是"随意用珠子名"，本轮起废止**。

---

## 四、避重规则

- 新取的**姓名（3 字）**，⛔ **不与"已用姓名"相撞**。
- 新取的**字（2 字）**，⛔ **不与"已用字"相撞**。
- 手串名 / 旧名 与 新名 之间，由**身份表别名**三方命中同一条记录（遵 v175 §二）。
- 已用清单见 §八。

---

## 五、男相口径（用户 2026-10-08）

- **核心团 10 位全员为男**；冰红茶（江冽茗）、粉黛熊（温茸之）皆为**男相**。
- **"娇憨 / 憨软"是男孩子的反差萌**，⛔ 非女性、⛔ 无女儿态。
- 凡带"温柔 / 细腻 / 憨软 / 守灯 / 听雨"意象者，一律按**男子也成立**来写。
- （轮换位、院外配角**不受此限**。）

---

## 六、命名流程（开一只，走一遍）

> **新沁灵开沁 → 按本规格取 2–3 组候选 → 由玩家拍板 → 入库。**

1. **读手串名**：看这只沁灵的**手串名意象**（冰 / 茶 / 柿 / 算盘 / 粉黛 / 熊 …）。
2. **取 2–3 组候选**：每组＝姓名 ＋ 字 ＋ 人物诗 ＋ 八字；**每组附一句话取用理由**。
3. **自检**：格式合规（§二）＋ 取材合规（§三）＋ 避重（§四）＋ 男相（§五）。
4. **交玩家拍板**：由用户择定一组。
5. **入库**：写入身份表，并登记进 §八 已用清单。
6. ⛔ **不替玩家点人、不替玩家定案**；候选给足，拍板留给玩家。

## 七、铁律

- ⛔ **手串名只作对应关系、不进姓名栏**（遵 v175 用户裁定）。
- ⛔ **不直接用手串（珠子）名当人名**（本轮起因）。
- ⛔ 姓名 / 字 / 人物诗 / 八字，**四件套缺一不可**。
- ⛔ 与已用姓名 / 字**不得雷同**。
