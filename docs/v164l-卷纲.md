## 〇、先认错：v1 的「散」是根本性错误

v1 我写「岁除灵潮退潮，未登名者尽散」，还专门解释「散不是死，是淡到没有人看得见」，还把它写进术语表、说它「比死更疼」。

**这个设计是错的，错在它没有现实载体。** 玩家手里握着一串实物——串在，就看得见、摸得着、盘得动。我发明了一套「淡到看不见」的衰减机制，玩家**无法验证、无法阻止、无法挽回**，只能在界面上看一只 3D 模型越来越透明。那不是恐惧，那是耍玩家。

**死亡必须是玩家真的会遇到的、且真的能共情的：**
- 我把它弄丢了，找不到了。
- 我把它送人了，它跟着别人走了。
- 它被虫蛀了，我救不回来。

这三条疼得多，而且**玩家能预防、能后悔、能挽回**——这才是能让人投入的恐惧。

v1 里所有「散」的用法（岁除死线、长者位失效、卷三转折、术语表、自评）**全部作废重写**。

**v3 追注**：用户亲自定下「不应该主动把它们写死」之后，上面这三条也已**降级**——
它们不再是主线用来制造失去的手段，而只是**玩家可能亲手造成的意外**。
挽回机制全部保留（那是给玩家的选择权），但**主线不主动触发任何一条**。详见 §一。

## 一、岁除与「风险」：盘点，不是清算

### 1.0 最高原则（用户亲自定的，优先级高于本卷纲其他一切）

> **系统不主动杀。**

三条现实死因（丢了 / 送了 / 蛀了）只作为**玩家可能亲手造成的意外**存在，**绝不是剧情里的安排**。

**⛔ 写手纪律（给第二步写剧本的人）：**
1. 主线剧本**不得**出现「它就丢了」「它被蛀了」「这一卷送走一只」作为转折或高潮
2. 剧本**不得主动制造**任何一只的死亡 / 蛀蚀 / 送出状态
3. 剧本**可以引用玩家的选择后果**（玩家自己标了"已送出"，剧本可以说"它在新主人那边"）——**引用 ≠ 制造**
4. 被玩家无视的蛀一期，剧本**不许说**「你害了它」

**这一条取代 v2 整节。** v2 我把三条死因当成了主线的失去机制——送人当卷二第一次失去、岁除当赌注、蛀当两难。**那套思路是错的：它把玩家最珍视的东西变成了剧情的耗材。** 一个机制一旦由剧情安排，它就不再是"风险"，它是"剧本"。
### 1.1 岁除：一年一次的**盘点**，不是清算

**岁除 = 公开检阅 + 年度盘点。**

它保留"可数的日子"这个唯一的优点，但含义彻底改。岁除这天做三件事：

| 岁除这天 | 说明 |
|---|---|
| **晋阶公示** | 这一年谁往上走了，一眼看见 |
| **名位落定** | 岁除前定的名位，这天挂牌 |
| **并肩** | 你和谁站在一处 |

**残酷来自横向对比，不来自纵向清算。**

> 你站在人群里，看见别人比你走远了。**没有人宣判你，只是你自己看见了。**

**岁除这天最重要的一幕：你能带去、护住的数量有限。**
带去的几只跟你一起经历这一年的大事；没带去的**在巷里好好待着，第二年你出去的时候它还在**。

⛔ **"不带" ≠ "会出事"。** 这一条必须写死，否则又滑回"惩罚关系不够"（见 §3.1）。

**⛔ 岁除不再是任何一只的赌注。** 主线不得在岁除前后安排"谁撑不过去"。
### 1.2 丢失：只是「找不到了」，不是「没了」

**现实载体**：玩家真的找不到。代码现状**没有"丢失"字段**（`item` 要么在库要么被送人），需新增（见 §五）。

**挽回 = 认路能力 = 亲密度档位**（这一条 v2 的设计是对的，保留）：

| 亲密度 | 丢了的串会怎样 |
|---|---|
| 照面 / 眼熟 | 只能说出一个**方向**：「它好像往东边去了。」你自己去找 |
| **相熟** | 能指出**确切位置**：「在你上次放外套的那个口袋。」 |
| **通意** | **它自己走回来**（第一次免费） |
| 同心 / 沁透 | 走回来，且**不掉阶** |

超期 30 天它才自己走回来 → **修行进度倒退一阶**（⛔ 不是失去——它还在，只是不再往前长了）。

丢失是三类里唯一**免费挽回**的，因为"找东西"是玩家能主动做的事。设计上要鼓励玩家去找。

⛔ 主线**不得**安排"这一章它就丢了"。丢失只发生在玩家真的找不到的时候。
### 1.3 送人：不是失去，是搬到了你看不见的地方

**现实载体**：`item.gifted`（布尔）+ `item.giftedAt`（时间戳）已存在，且全项目只用于列表显示和筛选器（`app.js:1881-1883` 手动置位）——**这是一条白捡的线**。

因为是玩家手动声明的，剧情必须尊重：**"你说它送人了，它就是走了"**，不能写成"其实是误会"。

**但送人不等于死。** v2 给它的定性我保留，那一条是对的：

> **送人不是失去，是把最深的信任放到别人手上。**
> 它在新主人那里**照样活着、照样在修行**。它不是消失了，是**搬到了你看不见的地方，还在往前走**。

**v3 改的只有一点**：⛔ 不许把它写成"失去"、不许让它承担任何一卷的转折。

**它在线上永远是活的：**
- **≤ 14 天**：可赎回（你去看它，它认得你，你带它回来）
- **> 14 天**：需要新主人同意——剧情里的一次选择，不是数值判定
- **超出窗口也不是失去**：它只是**换了个邻居**。剧本里它依然有回响，只是不在你身边了

**送人不扣任何亲密度。** 这是最重的一次托付，不是惩罚。
它也因此是**亲密线里分量最重的一次给出**——你把最亲的那只放到别人身边，从此它长成什么样，有一半你看不见了。
### 1.4 虫蛀：真实风险，但不是剧情事件

菩提根**真的会生虫**。这是玩家**天天在承担、却完全看不见**的唯一风险。

| 阶 | 玩家看到的信号 | 后果 | 能不能救 |
|---|---|---|---|
| **一期 · 起蛀** | 纹路**断了一线**；盘的时候声音变闷 | 无 | ✅ **完全治好**，耗时约 7 天 |
| **二期 · 蛀深** | 局部**起空**、发脆 | **修行进度倒退一阶** | 🟡 治不好，**能止损** |
| **三期 · 蛀透** | 一碰就掉渣 | 彻底不成器 | ❌ 不可逆 |

⚠️ **"掉一阶"是修行倒退，不是失去。** 掉到凝形以下，它就变回一串普通好串——**它还在，还是它，只是不再修行了。** 这句要跟 UI 一起说清，否则玩家会误以为掉阶＝死。

**⛔ 不许在主线剧情里安排某只必然走到三期。** 蛀到哪一阶，只取决于玩家看不看信号、动不动手。
**⛔ 玩家无视了一期信号时，剧本不许说「你害了它」。** 它只说「它还在，只是慢了一点」——**理由归玩家，不归剧情。**
> **这仍然是我最担心滑向"罪归玩家"的一条线**（见 §七）。主理人已批准的硬线原样保留：**信号早到玩家无法说"我没看见"；早发现就一定救得回来；但救它要花掉 7 天。**

### 1.5 挽回机制必须**真的**能挽回（硬性验收标准）

这三条机制存在的意义是**给玩家选择权**。所以它有一条比机制本身更重要的验收线：

| 机制 | 验收标准 |
|---|---|
| 认路 / 走回来 | `bond` 达到阈值**必须真的会触发**，不能只写进文案 |
| 14 天赎回 | ⛔ **依赖 `item.giftedAt` 可靠**。现在 `app.js:1883` 取消"已送人"会把它置 `null` → 玩家误操作取消再勾选，**时间戳丢失、窗口重置**。见 §五 |
| 蛀一期可治 | ⛔ **信号必须早到玩家无法说"我没看见"**（主理人已批准）。早发现就一定救得回来 |

> **一句话判断标准**：如果玩家照着 UI 提示做了，**结果必须是真的**。
> 做不到，那就不是"有代价的选择"，是"耍玩家"。

**这三套机制在 v3 里还有一个共同作用**：它们让"玩家可能亲手造成的意外"和"剧情安排的失去"在体验上**完全分开**——
玩家的疏忽是**我的错**（可以后悔、可以补救），剧情的失去是**它拿走**（无处可挽回）。
**只有前者存在。** 这是 v3 全部设计的落脚点。

### 1.6 主线张力从哪里来（改写）

既然死亡不担任转折，主线冲突全部转到**修行与争位**：

| 张力源 | 具体是什么 |
|---|---|
| **① 争名位** | 名额有限、岁除前定。**这是唯一的主线主轴** |
| **② 同辈比较** | 岁除这天所有人的进度一目了然。卷三"名额不够分"就建立在这个上 |
| **③ 抉择代价** | 修蛀要 7 天，去争名位也要那 7 天。**但这不再是剧情给的绝境——蛀是玩家自己发现的，所以"你怎么不去治"是玩家的选择，不是剧情的安排** |
| **④ 有限的注意力** | 队伍规模上去了，但你的时间没变。十几只，每只都要照顾。**这是"博爱的人"的真实代价，不是惩罚** |

**新的公式**：

> 你只有两只手。巷里有十几张嘴，还有几个名额要抢。
> **「来不及救」和「不救」都不是主线给的剧情，是你自己的选择。**

### 1.7 风险提示的 UI 口径（给 UI / 架构师）

三条死因要写进**设定手册与 UI 提示**，但必须让玩家一眼看出：**这是风险提醒，不是剧情预定。**

| 场景 | 提示口径 | ⛔ 不许说 |
|---|---|---|
| 虫蛀一期 | 「纹路断了一线。**现在处理还来得及**，约需 7 天。」 | 「危险」「即将失去」「它快不行了」 |
| 已送出 14 天内 | 「已送出 N 天。**你还可以去看它。**」 | 「后悔了吗」「它走了」 |
| 丢失 | 「你有一只不见了。它在等你找。」 | 「它可能回不来了」 |
| 掉阶（蛀二期止损后） | 「它还在。只是不再往前长了。」 | 「它废了」「它死了」 |

**三条通用禁令：**
1. ⛔ 不用红色、不用感叹号、不做弹窗。**风险提示不是警报，是说明书。**
2. ⛔ 任何提示都**不引用剧情**。不许出现「岁除要到了，你还有 20 天」这种把风险和主线绑死的措辞
3. ✅ 提示只陈述**事实 + 可选项 + 代价**（蛀了 / 现在处理还来得及 / 约 7 天）。**不加情绪、不加责备、不加倒计时。**

## 二、渐进扩员：角色随挂瓷一个个进来

### 2.1 机制事实

- `PLAYABLE_CATS = ["菩提"]`（`app.js:77`）——**盘玩只对菩提生效**
- 阶段由「挂瓷后天数 ∧ 盘玩次数」双条件派生（`STAGE_DAYS = [0, 7, 30, 120]`）
- 沁灵是**挂瓷那一刻**诞生的（`born()` 掷性别、记里程碑）

所以扩员是字面意义上的：**玩家挂瓷一只，巷里就多一个人。节奏在玩家手上。**

### 2.2 规模分级：人多 = 新的矛盾，不是新的爽感

| 当前在册 | 主线称谓 | 能做什么 | **这一档的矛盾源** |
|---|---|---|---|
| **1** | 就它一个 | 自保。看得见，帮不上 | **孤独**：所有事它一个人扛，且它自己不慌——你才慌 |
| **2–3** | 两三个 | 互相照应 | **不够**：出事只能派一个去，派谁就得罪另一个 |
| **4–6** | 几个 | 能分工、能去争 | **分薄**：一个人出事，剩下的人不够替补 |
| **7–12** | 一巷 | 能护、能挡、能分头办事 | **分名额**：名位不够分，**第一次要跟人抢自己人** |
| **13–24** | 一巷人 | 能渡劫、能自立门户 | **名位就那么几个**：这已经不是分薄了，是**必须有人落榜** |

> **这张表就是"人手不够"的设计。** 队伍小不是弱，是**另一种难**。所以主线**在任何规模下都能跑**，只是内容不同——不需要"必须挂满 24 只才能玩主线"。

### 2.3 「开沁 → 入队」设计：每只新来的必须带矛盾进来

**通则（这一条是整个扩员机制的引擎）：**

> **每一只新挂瓷的沁灵入队时，必须在它入队的那一卷制造一次"要不要带上它"的争论。**

这样扩员就变成了**剧情引擎**，而不是"人数 +1"。具体分工：

| 新来的是什么型 | 它带来什么 | 它制造什么矛盾 |
|---|---|---|
| `cool` / `aloof` | 办事利落、不废话 | 直接跟现有争先位撞上 → **内部竞争** |
| `mystery` / `pampered` | 知道别人不知道的事 | 解锁一段信息，**但它只说一半** → 逼你选信不信 |
| `gentle` / `sweet` / `sentimental` | 会照顾人，队伍情绪稳 | 大家开始依赖它 → **依赖是危险品**（它一旦出事，全巷崩） |
| `heroic` / `wild` / `wanderer` | 能冲、能挡 | 它要往前冲 → **你要决定让不让人去冒险** |
| `scholar` / `dignified` / `calm` | 懂规矩、能记账 | 它会告诉你"这样做不合规矩" → **规矩和活路冲突** |
| `lively` / `cheeky` | 消息灵通、气氛好 | 藏不住事 → **它把不该说的说了** |
| **刚挂瓷没几天的新生** | 它什么都不会 | **"要不要把它也带去"——这是伦理困境，不是选择题** |

最后一行是我特意留的：**一只还没成长的小家伙，成了队伍里最沉的那个拖累。** 这一条能让"人多"变成负担，而不只是爽点。

### 2.4 五卷重排（每卷都能在低规模下跑）

| 卷 | 章 | 在册规模 | 核心冲突 | 岁除那天 |
|---|---|---|---|---|
| **一 · 认得** | 1–4 | **1 起** | 不是"争"，是**知道有这件事**。第一次有人告诉你岁除是什么 | 你第一次知道"能带去几只" |
| **二 · 争** | 5–9 | 2–6 起 | 第一个名位。同门劝退、试探、拉拢 | 第一次看见**别人比你走远了** |
| **三 · 决** | 10–15 | 4–10 起 | 名单出来，**名额不够分**。第一次要跟自己人抢自己人 | 第一次**带不下所有人** |
| **四 · 渡** | 16–21 | 7–16 起 | 岁除逼近。有人赶不上，有人食言 | **谁跟你并肩，谁在巷里等** |
| **五 · 名** | 22–26 | 10–24 | 岁除到了。**榜挂出来了** | 你带去的几只、留下的几只，**都好好的** |

⛔ **全表无死亡。** 少了的那几只 = "没带去"，不是"没了"。
"人手不够"的紧张感仍然在（卷三"名额不够分"、卷五"榜上就那么几个名字"），但它的结果是**落榜**，不是**消失**。

**规模不够时的兜底（重要）**：
- 每卷解锁**只靠 stage 和 days，不靠队伍规模**——小队伍玩家永远不会被卡住
- 每卷有**"人多版"和"人少版"两套开场**（不是两套结局，结局统一）
  - 例：卷三"名额出来"的场面，20 人在场时是一场群戏；只有 2 人时变成"它自己跑去看榜，回来跟你讲"——**信息量一样，孤独感完全不同**

### 2.5 主串数量重新建议：**上限 24 · 设计基线 12**

v1 建议 24，那是按"一次到齐 24 只"算的。**渐进加入改变了这个问题的性质**：

| 数字 | 判断 |
|---|---|
| **≤ 3** | 能跑完主线，但卷三"名额不够分"这一整卷会**失去张力**（没有多余的人可分）。这不是内容缺失，是**主题落空**——卷三讲的就是"必须有人落榜"，只有 3 只时没人需要落榜 |
| **6–12** | ✅ **最佳区间**。够触发"不够""分薄""必须有人落榜"全部矛盾，但又不会变成点名册 |
| **13–20** | 更好。卷四"护"和卷五"落榜"都更立体 |
| **24** | 建议作为**上限**。超过 24 的不设位、不进主线，只走支线 |
| > 24 | ❌ 稀释。24 只已经是"一巷人"的完整感，再多每个人都只有 < 3 场戏，退化成背景板——**那就等于又回到"每个串都一样"** |

> **我的建议**：卷纲按 **12 只的设计基线**写（所有主线场面保证 12 只在场时成立），实际玩家在 1–24 之间浮动，靠 §2.2 的规模分级接住两端。
> **最低要求不是 24，是 6。** 低于 6 建议提示玩家"主线最好看的部分要人多"。

## 三、亲密系统怎么接（返工 3）

> ⚠️ **说明**：返工 3 的正文在我这里被截断了（只收到标题「主线的死线要能接上情感系统的『亲密』」）。我按字面理解处理——**把主线的死线（岁除）和亲密度档位焊在一起**。若你的原意不同，请补正，我再改。

### 3.1 核心机制：亲密度决定你「带得走几只」

> ⚠️ **v3 改。** v2 我写的是"亲密度决定你**保得住**几只"——**那个设计作废**。"关系不够就会失去"本身就是一种惩罚，与"系统不主动杀"冲突。

**现在的定义：亲密度决定「容量」，不决定「生死」。**

> 岁除、年节这类要出头的时刻，**你能带在身边、能护在身后的数量**，取决于你在它们身上花过多少。
> **但带不了的那只，不会因此消失。** 它只是不在你身边，各自去过。

**为什么这样才对**：
- 有**容量感**（人少就是带不了几个）→ 事业线有分量
- 没有**生死感**（带不了 ≠ 死）→ 不违反新原则
- 而且它造出一个**真正有意思的选择**：带谁去？带去的会经历大事，不带的会在巷里等
- **这个选择的代价是「错过」，不是「死亡」** —— 温和得多，也更不像在惩罚玩家

| 亲密度 | 岁除能带几只 | 危机时能护住几只 | 面对丢失 |
|---|---|---|---|
| 照面 / 眼熟 | **带不走**——它还没强到能跟你出门 | 护不住 | 只能说出一个方向 |
| **相熟**（30） | ✅ 能带 | ✅ 能护 | 能指出确切位置 |
| **通意**（60） | ✅ 能带，而且**它自己会要求跟你去** | ✅ 能护 | **自己走回来** |
| 同心（120）/ 沁透（240） | ✅ 站你身边像理所当然 | ✅ | 走回来不掉阶 |

> 第 2、3 行是关键：**照面/眼熟 不是"会失去"，只是"带不走"。** 一只凝形期的小家伙跟着你出门只会拖累你，这是**常识，不是惩罚**。
> 而「通意」那条"**它自己会要求跟你去**"，正好接上 `BOND_CALL_AT = 60`（通意它改口叫你的名字）——**这条现成的、写好的细节，在这里变成了剧情。**
### 3.2 亲密的三个真实功能（不是装饰）

1. **带得走几只**（岁除 / 危机时的**容量**）——⛔ 不决定生死，见 §3.1
2. **认路能力**（丢了之后它能不能自己找回来）——照面说方向 / 相熟指位置 / 通意自己走回来
3. **称呼**——`BOND_CALL_AT = 60`（通意）它会改口叫你的名字。**这条已经是现成的、写好的细节，在 §3.1 里直接变成了剧情**：通意之后，岁除那天它会主动要求跟你去

> 第 2 条是**唯一一条"能力"而不是"待遇"**的。丢了的时候能不能自己回来，靠的是你陪它的那些天。
> 这样"多陪"有了两种回报：一种是你自己记得，一种是真的有用。

## 四、爱情向（返工 4 · 红线撤销）

### 4.1 尺度重设

> **家人般的依恋与照顾是底色，恋爱与亲密是其中可以显著存在、并且可以很强的一部分。**
> **主线仍然是修行事业线**（不要求恋爱向），但**支线 / 亲密剧情层可以全力做恋爱向**。

我不设"不许恋爱"的线。我自己设的这条线是错的，向主理人认错。

### 4.2 防"数值堆砌"的三条硬规则

用户的诉求是真实的：**「我这么多菩提根难道还没有体现我是一个博爱的人吗」「开后宫」**。
问题不在"多线"，在"多线如果只用一条数值轴表达，必然变成 8 个一模一样的进度条"。

**规则一 · 数值可并行，剧集独占。**
- 亲密度（`bond`）**完全允许并行**——你确实可以同时和 12 只都很亲近，爽感不损失
- 但**主线每一卷的大事件只推进一只的专属剧情**（因为"那一场"只有一个）
- 于是：**8 条满好感的恋人线 + 每只有一段别人没有的专属剧情**，而不是 8 条同步爬的进度条

**规则二 · 阶段只由"只属于两个人的事"推动。**
- 盘玩、送礼、问候 → 只涨**亲密度数值**，且只推动「照面 → 眼熟 → 相熟」这一段（涨得快）
- **阶段不能靠刷。** 往上（相熟 → 通意 → 同心 → 恋人）**必须**是：一次主线大事件，或者玩家主动触发的一场**独占场景**（只有它在场）
- 换句话说：**你可以对 12 只都很好，但你没法对 12 只同时"好到那一层"——除非你真的为每只做了一件事。**
- 这一条是"开后宫"能成立的技术前提：它让每条线都有**独一无二的内容**，而不是同一套模板跑 8 遍

**规则三 · 恋人阶段是"排他事件"，不是"排他状态"。**
- 两只同时到「恋人」是**允许的**（数值并行）
- 但进入恋人阶段的那一刻，会**冻结**同期其他沁灵推进"专属剧情"的可能（不是降好感，是**排队**）
- 于是产生的不是数值烦恼，而是**真实的情感张力**：你把一只推到恋人档时，其他只不会消失，但它们**会感觉到**。这正是"后宫"该有的东西——修罗场是剧情，不是数值。

### 4.3 博爱 vs 专一：给一个真实取舍，但不给惩罚

用户说自己是"博爱的人"。所以**这个选择绝不能惩罚博爱**。我的设计是**两条线并行解锁，不互斥**：

| 取向 | 解锁什么 | 代价 |
|---|---|---|
| **广度（博爱）** | 同时与 6 只以上达到「相熟」→ 解锁**群像线**：巷子真的变成一个家。主线里多出"大家一起"的场面（一起护、一起分、一起挨骂） | **无代价**。这是玩家应得的 |
| **深度（专一）** | 某一只达到「同心」以上 → 解锁**它的专一结局**：岁除那天，它是唯一能跟你带走的那只 | 无代价。**只是别人到不了那一层** |

**两条可以同时开。** 博爱的人照样能深爱一个人。**不做二选一，因为那是在惩罚用户的偏好。**

> 真正的取舍在别处，已经有了：**你有两只手。** 治蛀要 7 天，赎回要 6 天，岁除只有 20 天。**这才是取舍**——不是"你爱谁多一点"，是"这 20 天你先做哪一件"。

### 4.4 亲密线在主线里的位置（不喧宾夺主）

- 主线**大事件**始终是修行事业线（岁除、名位、蛀、赎、送）
- 但**每一卷的大事件，都有一个"只属于某一只"的私人段落**（卷末或卷中，2-4 场戏）
- 这一段就是恋爱向的落点：**它发生在主线之内、但不占用主线的冲突**
- 所以恋爱向不需要"另一个系统"，它就长在主线里

## 七、自评

**v3 最核心的一处转变，不是新写了什么，是拆掉了一个东西。**

v2 我把三条现实死因当成了主线的失去机制——送人当卷二第一次失去、岁除当赌注、蛀当两难。**这套思路是错的：它把玩家最珍视的东西变成了剧情的耗材。** 一个机制一旦由剧情安排，它就不再是"风险"，它是"剧本"。

v3 之后：
1. **系统不杀玩家。** 这不只是写法洁癖——它让"挽回机制"这个东西**真正有意义**。能挽回的东西必须是玩家造成的风险，否则挽回就是演给你看的。
2. **岁除从清算变盘点。** 残酷感从"你会失去"变成"**你看见别人比你走远了**"。这更成人，也更持久，因为它不需要任何人消失。
3. **亲密度从"生存资格"改成"容量"。** 关系不够的代价是「带不走」，不是「会失去」—— 前者是常识，后者是惩罚。

**我预计最容易写崩的地方（换了一条）：**

> **"不主动杀"这条原则，最容易的执行失败是"忍不住暗示"。**

写手写到卷四卷五，看到别人有成长、有名位、有了变化，很容易顺手给某只安排一个"它最近有点不对"来制造戏剧张力。**这就是变相的系统杀。**

所以我给自己的硬线是：
> **戏剧张力只能来自「你和它们的差距」和「你要在多少只之间分配」。**
> **不能来自「谁要出事了」。**
> 一旦发现自己在写"这一卷它会……"这种句子，就是越线了。

**另外，蛀这条线仍然是全卷纲里唯一可能滑向"罪归玩家"的地方**——即使原则改了。所以主理人批准的那条硬线我原样保留：
**信号早到玩家无法说"我没看见"；早发现就一定救得回来；但救它要花掉 7 天。**
**冲突必须在「取舍」里，不许在「疏忽」里。**

**返工 3 的完整版我收到了**（亲密度从好感度变生存资格）。方向我采纳，但按新原则把它改成了**容量**——见 §3.1。
