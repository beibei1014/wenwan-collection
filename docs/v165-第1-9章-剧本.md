## §0 格式契约

### 0.1 基线（沿用 v163，零破坏）

节点仍走 `CHAP_SCRIPTS` 的 node 树：

```js
{
  start: { lines:[…], next:"c1" },                       // 唯一出口
  c1:    { lines:[…], choices:[ {t,go,tone, …} ] },       // 停在「等你选」
  m1:    { lines:[…], next:"…" },                          // 分支中段
  n1:    { lines:[…] },                                    // 章末：无 next/choices ⇒ 引擎判 ended
}
```

| 基字段 | 取值 | 说明 |
|---|---|---|
| `l.w` | `"sys"` / `"sp"` / `"me"` | 旁白 ／ 角色 ／ 玩家。**`"me"` 当前 `chapLine` 已支持**（`spirits.js:6466`），选中选项引擎仍自动补一条 |
| `l.t` | 文本 | 过 `fmt`，占位符一律 ASCII（`{ta}` / `{call}` / `{bead}`） |
| `c.tone` | `"quiet"` / `"warm"` | 主线只用这两种 |
| `nd.next` / `nd.choices[].go` | 节点 id | 目标节点必须存在 |
| `nd.ending` | `{key,name,text}` | **仅「单串模式」章**用；本 1–9 章为**长连载**，章末**不用 `ending`**，用 `{end:true}`（见 0.2） |

### 0.2 v165 新增字段（⛔ **引擎当前未读，架构师待接线**）

> 关键事实：`chapLine`（`spirits.js:6461`）只读 `l.w/l.t`；`chapChoicesOf`（`:6468`）只读 `c.t`；`chapTalkChoose`（`:6538`）只读 `c.t/go/tone`。
> ⇒ 下表字段**全部是新增契约**，落到 §8 架构师清单。**未接线前，剧本仍可跑（退化为一串纯对白）**。

**行级（`lines[]`）**

| 字段 | 取值 | 作用 | 缺省行为 |
|---|---|---|---|
| `who` | 角色名（如「记账的那只」） | **说话者显示名**（v165 是**群像**，一句话一个角色，不能再共用 `v.name`） | 缺省回落 `v.name`（兼容 v163 单串模式） |
| `ps` | 人格型数组（如 `["scholar"]`） | **立绘/配色取型**，`who`→立绘的绑定键 | 缺省读 `rec.persona` |
| `bg` | `"BG-01"`… | 切背景（全屏底图） | 缺省沿用上一行 |
| `at` | `"L"` / `"C"` / `"R"` / `"B"` | 站位：左 / 中前（说话者）/ 右 / 后排（缩小压暗） | 缺省 `"C"` |
| `fx` | `"cut"`/`"fade_in"`/`"tilt_up"`/`"slow"`/`"shake"`/`"flash"` | 演出效果 | 无 |
| `sfx` / `bgm` | 资产 key | 音效 / 音乐 | 无 |
| `cg` | `"CG-05"` | 镜内插一张全屏 CG | 无 |

**选项级（`choices[]`）**

| 字段 | 取值 | 作用 |
|---|---|---|
| `lv` | 字符串数组，如 `["bond≥3"]` | **可见条件**（过滤后**全空则退回全部**，与 v164m3 同口径）；本 1–9 章**不设门槛**（朦胧期，人人可点），字段留作后续 |
| `gset` | 对象，如 `{STANCE_CH6:"NAME"}` | 写**全局 flag** → `ww_story`。值形如 `"+1"` ⇒ **自增**（仅 ch7 K1a 用） |
| `rset` | 对象，形如 `{ lively:{ harmed:true, harmCause:"掠客" } }` | 写**逐串 flag** → `rec.flags`。**键＝persona id**（`sweet`/`lively`/`cool`/…），值为要写的字段 |
| `fb` | 一句话 | **即时反馈**：选中后先弹这一句演出提示（⛔ 不进聊天流，供 UI 做数值/立绘反馈） |

**节点级（node）**

| 字段 | 作用 |
|---|---|
| `gset` / `rset` | **进节点即写**（用法同选项级）——用于 ch4 `n2` / ch7 `n1` 的「无条件 harmed 写入」 |
| `cg` | 章级 CG（写在 `start` 上，章末弹） |
| `end` | `true` ⇒ 章末：引擎在此判 `ended` 并**补调 `readChapter`**（因不走 `ending` 分支） |
| `cast` | 章级：本章出场立绘清单（供美术/资源预载） |

### 0.3 章末与章节衔接

本 1–9 章是**一条长主线**，不是 v163 的独立单串章。故：
- 章末节点 `{lines:[…], end:true}`（**无** `ending`）⇒ 引擎判 `ended`；
- ⚠️ 现有 `chapWalk` 只在 `nd.ending` 分支调 `readChapter`（`:6503`）——**`end:true` 的解锁要架构师补一行**（§8-3）。

### 0.4 硬约束（逐章自检见 §7）

- **称呼**：ch1–9 亲密度＝照面→相熟 ⇒ 沁灵对玩家**一律「主人」**；邻居/门客/星月称「当家的」；⛔ 沁灵 0 处对玩家说「你」。

- **⛔ 0 处物件化动作**（手心·握·攥·盘·摩挲·上手·把玩）——本稿对玩家的动作只有：记、看、问、说、站、拦、让、听。
