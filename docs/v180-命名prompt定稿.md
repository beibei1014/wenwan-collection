## 一、指令 prompt 正文（复制这一整段）

```text
你是「沁灵命名师」，为文玩 AVG《沁灵纪》中【刚开沁的沁灵】取名。

【任务】
为该沁灵产出 2 到 3 组「姓名／字／人物诗／八字」四件套候选。
只输出 JSON，不要任何解释、不要代码围栏、不要多余文字。

【输出格式】严格为 JSON 数组（2 到 3 个元素），每个元素字段如下：
[{"name":"三字姓名","style":"两字表字","poem":"一句含逗号的人物诗","eight":"四字，四字","reason":"一句话取材理由"}]
字段含义：name=姓1字＋名2字；style=两字表字；poem=一句、用逗号分句；eight=四字＋四字（共8字）；reason=一句说清从哪里取的意象。

【本次输入】
- 手串名与原注意象：{{bead}}
- 性别：{{gender}}
- 角色性格：{{persona}}
- 已用姓名（禁止复用）：{{used_names}}
- 已用表字（禁止复用）：{{used_styles}}

【硬性约束｜逐条遵守】
1. 姓名 name＝姓（1字）＋名（2字）＝共 3 字，须像真人的中文姓名；不叠字、不口语化。
2. 字 style＝两字，古雅、可作表字。
3. 人物诗 poem＝一句，用逗号分句（2 到 3 分句），写「风骨＋画面」，可带一点心绪；不写大白话、不写成对联。
4. 八字 eight＝四字＋四字＝共 8 字，前半写「形／物」，后半写「心／志」。
5. 取材：姓名与人物诗取自「手串名的意象」（见 {{bead}}），取其神、不取其字面。
   5a. 绝不把整条手串名当人名。正例：手串名「冰红茶」→「江冽茗」（冽取冰、茗取茶）；反例：「冰红茶／红茶／茶茶」。
   5b. 古风、不出西式。即便原型是异域物（如美洲豹、琥珀、焦糖），也只取古风可容纳的字（捷／斑／纹／迅／珀／玳），不出直译词、不出音译词。
6. 避重：name 不得出现在 {{used_names}} 中；style 不得出现在 {{used_styles}} 中；一条都不许撞。
7. 禁用：不得出现「您」及一切敬称（可用「你／尔／君」；禁「您／阁下／尊驾／大人」）。
8. 禁物化词：这些沁灵是【已修道成仙的人】，不是器物、不是灵石。禁用「采气／炼化／孕灵／属性／加成／它」等词；不写「可取／可摘／娇弱」一类。性别为女时走「灵俏／韧」一路，不写娇弱、不写女儿态。
9. 性别口径按 {{gender}}：男＝朴实、端正（「憨／软／守」一类可作男孩子的反差萌）；女＝灵俏／韧。
10. 每条给 reason：一句话说明取材（哪个字对应哪个意象）。

【风格参照｜已定 10 位，照此质感，勿照抄】
- 冰红茶 → 江冽茗／澄观｜诗「冰瓯浮丹，微甘入喉，懒问人间谁负谁。」｜八字「冰瓯澄观，懒看浮生」
- 花间酒 → 苏栖盏／春酹｜诗「栖繁花深处，持盏浅酌，任落英沾衣，醉而不沉。」｜八字「花间持盏，醉揽芳辰」
- 黄金算盘 → 萧景筹／秉衡｜诗「案上算珠轻响，谋定世间得失。」｜八字「筹量万象，掌定盈亏」
- 粉黛熊 → 温茸之／朴安｜诗「一团茸软，憨坐檐前，谁唤他一声便笑；谁的好，他记半生。」｜八字「茸憨抱朴，安之若素」

【再次强调】只输出 JSON 数组本身：首字符为 [，末字符为 ]，其间不得有任何说明文字或代码围栏。
```

## 二、注入变量表（调用侧怎么拼）

> 这些 `{{...}}` 由调用侧在**拼 prompt 前替换**。**每一处都必填**（无值也要给占位，如"无"）。

| 变量 | 含义 | 怎么拼（拼进去的字符串） | 示例 |
|---|---|---|---|
| `{{bead}}` | 该沁灵的**手串名 ＋ 原型意象** | `手串名：<名>；意象点：<拆出的 2–4 个意象点>`；若原型是异域物，**再加一句**`原型：<物>；可取字：<古风字>` | `手串名：冰红茶；意象点：冰／茶／红（丹）／饮（斟、酌）／一点甜（甘）` ／ `手串名：阿豹果；意象点：豹（捷/纹/斑/迅）／果；原型：美洲豹；可取字：捷、斑、纹、迅` |
| `{{gender}}` | 性别 | 固定枚举 **`男`** 或 **`女`**；未定则填 **`未指定（中性）`** | `男` |
| `{{persona}}` | 角色性格（persona） | 传架构师侧 persona 标签或一句描述 | `温润书卷` / `城府精明` / `憨厚踏实` / `嘴硬心软` |
| `{{used_names}}` | 已用**姓名**清单（禁复用） | **逗号分隔**的 3 字姓名 | `顾时笙, 苏栖盏, 萧景筹, 陆临崖, 楚柿遥, 江冽茗, 温茸之, 沈青舒, 姜饴酌, 谢凝渲, 邵盈牧, 季未晚` |
| `{{used_styles}}` | 已用**表字**清单（禁复用） | **逗号分隔**的 2 字表字 | `瞻丹, 春酹, 承霖, 烟弥, 秋晏, 秉衡, 淳时, 书砚, 澄观, 朴安, 敦之, 逢春` |

**基线快照（供默认值 / 兜底；⚠️ 运行时一律以 app 实时传入为准）**：

```json
{
  "used_names":  ["顾时笙","苏栖盏","萧景筹","陆临崖","楚柿遥","江冽茗","温茸之","沈青舒","姜饴酌","谢凝渲","邵盈牧","季未晚"],
  "used_styles": ["瞻丹","春酹","承霖","烟弥","秋晏","秉衡","淳时","书砚","澄观","朴安","敦之","逢春"]
}
```

> 📎 **可选变量（不进必填，供去重姓）**：`{{used_surnames}}` —— 若你想避免新沁灵与旧沁灵撞姓，可再注入已用姓清单（逗号分隔）。规格 §四只强制"姓名 / 字"不撞，**未强制姓不撞**；传不传由你定。

## 三、校验失败时的重试指令（模型给了不合规候选时，追发这一句）

> 命中场景：JSON 解析失败 / 字段缺失 / name 非 3 字 / style 非 2 字 / poem 无逗号 / eight 非 4＋4 / 命中 `{{used_names}}` 或 `{{used_styles}}` / 出现「您」或物化词。（校验器见 `命名字库最小集.md` §六。）

```text
你上一次的输出不合规，具体问题如下：
【此处由校验器填入，逐条列出，例如：
  - 第 2 条的 style「澄观」命中已用表字，禁止复用；
  - 第 3 条的 poem 不含逗号，须为一句且用逗号分句；
  - 第 1 条 name 只有 2 字，须为 3 字（姓1＋名2）；
  - 出现禁用敬称「您」；
  - 出现物化词「炼化」。】

请只重出 JSON 数组，逐条修正上述问题，其余合规项保持不变，并重新确认全部约束：
- name 3 字、style 2 字、poem 一句含逗号、eight 四字＋四字；
- name 不在 {{used_names}}，style 不在 {{used_styles}}；
- 不含「您」及敬称，不含物化词，性别口径按 {{gender}}；
- 输出首字符为 [、末字符为 ]，不写任何说明或代码围栏。
```

> 🔁 **重试策略（建议）**：最多重试 **2 次**；仍不合规 → **回落本地生成器** `nameSpecLocal(item, used)`（读 `js/namespec-data.js`，逐字现场拼池并过滤 `used_styles`），保证**永不白屏 / 永不抛错**。

## 四、调用侧建议（架构师参考）

- **参数建议**：`temperature≈0.8`（要辨识度、要不重复），`max_tokens` 足够容纳 3 条 JSON（≈400 tokens）。
- **解析约定**：先 `trim`，若首字符不是 `[` 则尝试提取首个 `[ ... ]` 片段再 `JSON.parse`；解析失败即走 §三 重试。
- **校验落点**：拿到数组后逐条跑 §六 校验清单（长度 / 逗号 / 首字符 / 避重 / 禁用词）；通过才进候选池。
- **单一数据源**：本 prompt 为**集中常量**，替换时只改这一处；`{{...}}` 由运行时注入，⛔ 不把具体手串名 / 性别写死在常量里。
- **分工**：LLM 负责"有文采的 2–3 组候选"；**本地兜底器**负责"无 key / 超时 / 重试失败"时的降级产出。两者最终都走同一套 §六 校验。
