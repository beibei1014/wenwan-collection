## 〇、生成器怎么用它（算法，照着实现即可）

> 输入：`item.name`（手串名，如"油果果"）；`used`（app 传入的已用清单：`{surnames[], names[], styles[]}`）。输出：2–3 条 `NameCandidate`。

```
① 取意象：把 item.name 切成单字，逐个查 §一「意象字表」，
          命中则取其 nameChars；未命中的字跳过；全未命中 → 落到 §一「通用池」。
          （例：油果果 → "油"→[酥,润] · "果"→[栗,杏,圆]）
② 取姓：从 §二「姓池」随机取 1 个（⛔ 不在 used.surnames）。
③ 取名（2 字）：从①的 nameChars 里选 2 个（可跨意象拼，如 栗+杏）；
          ⛔ 拼出的 3 字姓名不在 used.names。
④ 取字（2 字）：按 §三「表字池」的组合思路拼 2 字；⛔ 不在 used.styles。
⑤ 拟诗：随机取 §四 一个 template，用①的意象字 ＋ §四 的「通用物象/动词/心境词」填槽。
⑥ 拟八字：随机取 §五 一个 template，填「象/性/心/志」四槽。
⑦ 校验：姓名 3 字、字 2 字、诗含逗号分句、八字 4+4；任一不合 → 重抽（最多 N 次）。
⑧ 产出 2–3 组（互不相同；避免同一姓重复）。
```

> 📘 **品味约束**（供 prompt 与抽查，非硬校验）：⛔ 不用手串名直接当人名；⛔ 不出现现代词；男相默认用"他"，女相用"她"（性别未定时用"他"作中性）。

## 三、表字池（二字表字 · 组合思路）

> 表字＝**两字**、古雅。三条主流路子。
> ⛔ **抽签规则（写死）**：生成器**只从「首字池 ＋ 尾字池」（路B 为「动字池 ＋ 名物池」）现场拼字**，拼出后**再按 `used_styles` 过滤**；⛔ **不得直接从 `示例` 取签**。

> 📌 **组合思路**：**路A**＝"心境字 ＋ 之"（稳、正）；**路B**＝"动词 ＋ 名物"（有画面、"憨 / 柔 / 朴"一路）；**路C**＝"两个雅字并置"（书卷气）。生僻字一律**不用**。
> ✅ **已清洗（本轮）**：把已用字的**组成字**——瞻 / 丹 / 春 / 酹 / 承 / 霖 / 烟 / 弥 / 秋 / 晏 / 秉 / 衡 / 淳 / 时 / 书 / 砚 / 澄 / 观 / 朴 / 安——**从各「池」与 `示例` 里全部剔除**。故任一「首字池 ＋ 尾字池 / 名物池」的组合，**都不可能**落在 `used_styles` 上。
> ✅ **校验结论（口径已与架构师实测对齐）**：三路共 5 个池（路A首 13 ＋ 路B动 8 ＋ 路B名物 8 ＋ 路C首 8 ＋ 路C尾 8）**去重后并集 41 字**；若按**抽签槽位**归并——**「首字位」并集 26、「尾字位」并集 15**；**上述三个并集与 `used_styles`（含朴安）交集均为 0**（node 实跑确认）。

## 四、人物诗模板（句式骨架 ＋ 可替换位）

> 诗＝**一句**、逗号分句（2–3 分句）。`{}` 为可替换位。

```
T1  拟人画面：   "{狸/人}{卧/坐}{处}，{象}{上身}，{一声/半句}{反应}。"
     例：狸奴卧绣，花影上身，一声嗯，便睡过去了。
T2  味觉叠压：   "{象}{香/软}，{含在/入口}，{最}{评价}。"
     例：栗香酥软，含在嘴里，甜得人心都化开。
T3  动作＋评：   "{象}{动}，{象}{动}，{人}{一笑/一诺}{扫尽/便生}{风尘/春色}。"
     例：剑过秋林，丹柿落肩，一笑便扫尽风尘。
T4  场景＋志：   "{处}，{动作}，{收句：其志/其守}。"
     例：窗畔新叶初生，执砚翻书，待人皆是一片赤诚。
T5  起句嵌名：   "{名/字}{作起句}，{象}{来}，{收句}。"
     例：春不晚，信先到，一枝桃花替你报了平安。
```
