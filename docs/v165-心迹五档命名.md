> 口径：这五档是**恋爱向「心意」的刻度**（逐串、0–300），与「羁绊八档」**两条线、各走各的**（对齐 UI §3.2 原文）。

---

## 一、这五档是什么（先把口径说清）

- **「心迹」**＝一只沁灵**对你那点另外的意思**，走得慢；**「羁绊」**＝你们**处出来的熟**，靠日子。两条各走各的，互不换算。
- 心迹是一个 **0–300 的刻度**，五个节点：`0 / 40 / 100 / 190 / 300`（＝ `HEART_MARKS`）。⇒ **五档**。
- ⛔ 心迹**只是刻度，不是开关**：它到「动心」**不等于**恋爱线自动开启——**恋爱线开启仍以 `v165-故事大纲.md` §10.1 第 4 条为准**（见 §四）。

---

## 二、定名（★ 正式稿）

| 档 | **档名** | 区间（心迹值） | 一句状态（世界观内说法） | **内心独白口径**（{ta} 自己心里的话） |
|---|---|---|---|---|
| 一 | **未起** | 0–39 | 心里还没往那上头去（心意刚起头，还没成波澜） | 「不过是多看了【称呼】一眼。……没什么。」 |
| 二 | **微澜** | 40–99 | 起了一点，自己还嘴硬 | 「【称呼】今天又来了。我数着日子呢。」 |
| 三 | **动心** | 100–189 | 认了：是动了心 | 「我算明白了——我对【称呼】，不只是惦记。」 |
| 四 | **倾心** | 190–299 | 心偏了，藏不住了 | 「家里都看出来了。我也不想再藏——这颗心，就偏给【称呼】了。」 |
| 五 | **相许** | 300（满） | 认定了，再不换人 | 「往后再难，我也不换人。这条路，我陪【称呼】走到头。」 |

> ★ **五档连读**：**未起 → 微澜 → 动心 → 倾心 → 相许** —— 正是「**心动 → 再放不下**」的推进：**还没起头 → 起了一点 → 认了 → 偏了 → 定了**。

> ★ **【称呼】＝运行时占位符**：按称呼规则解析（档 1–3「主人」／档 4–6「你」／档 7–8 `{nick}`／已立恋爱线则 `{lovecall}`）。⛔ 文案与正文**一律不写死具体称呼**——改口由玩家进度驱动，写死会跳档或与玩家实际档位矛盾。见 §五-3。

**内心独白的写法口径（为什么这么写）**：
- **一 / 二档（未起 / 微澜）**：**只到「在意 / 惦记 / 等你来」**，⛔ **绝不表白**（对齐 v164l §1.3「严格停在'在意/惦记'」）。
- **三档（动心）**：**可认心**；但**说不说出口**由剧情门槛决定（见 §四）。
- **四 / 五档（倾心 / 相许）**：**可独占、可认许**（对齐 v164l §1.3「倾心＝独占的亲密剧情；相许＝新的日常形态」）。

## 三、与「羁绊八档」不撞 · 核对

| 轨 | 档名 |
|---|---|
| 羁绊八档 | 照面 · 眼熟 · 相熟 · 同室 · 通意 · 同心 · 相知 · 沁透 |
| **心迹五档** | 未起 · 微澜 · 动心 · 倾心 · 相许 |
| 核对 | ✅ **无一词相撞**（逐字比对，无同词） |

- ⚠️ 唯一需留意：羁绊档 6「**同心**」与心迹「**动心 / 倾心**」同含一个「心」字，但**整词不同、且分属两条轨**，玩家侧不会混。⛔ **不建议改「同心」**（羁绊档已定稿）。

## 四、与 v165 恋爱门槛的口径（★ 别把「刻度」当「开关」）

| 事 | 认哪条 |
|---|---|
| 恋爱线**开启**（告白成立） | **`v165-故事大纲.md` §10.1 第 4 条**：`stage ≥ 4` ＋ 羁绊 ≥ 相知（档 7）＋ **玩家显式确认**。⛔ 心迹值**不是**开启条件。 |
| 恋爱向**台词资格** | 心迹 ≥「动心」**且** `stage ≥ 4`（沿用 v164l §1.3 / §4.2）。⛔ 低阶段（stage 1–3）**0 处恋爱向台词**。 |
| 心迹**满档**（相许） | 结算**并进主线岁除**，⛔ **不另开恋爱终章**（v164l §1.3 定案）。 |

> ⚠️ 一句话给剧本：**心迹量的是「心走到哪了」；开不开线，看的是「够不够格、你点没点头」。两件事别混。**

## 五、接口（给架构师 / UI · ⛔ 本稿不改代码）

1. **单一数据源**：正式 `HEART_LV_NAMES`（索引＝ `lv`，0-based）应为——
   ```
   HEART_LV_NAMES = ["未起", "微澜", "动心", "倾心", "相许"]
   ```
   （替换现库内占位 `["未起头","微澜","动心","倾心","相许"]`；**仅 lv0 由「未起头」→「未起」**，其余四位一字不动。）
   ⛔ 档名**只此一处**；不得散进 CSS 类名 / `data-*` / DOM 硬编码（对齐 UI §3.2 单一数据源纪律）。
2. **档界不动**：`HEART_MARKS = [0,40,100,190,300]`。
3. **称呼占位**：凡出现称呼处（档名旁的独白 / 演出文本），统一用运行时占位符（建议 `{call}`），由称呼规则解析，⛔ 不写死。
4. **冻结态**（30 天未互动）：置灰 ＋ 冰晶图钉，**不掉分、不清零**；「相许」档需 30 天内有互动才续期（对齐 v164l §1.3 / §7）。⛔ 不写「掉分 / 惩罚」。
   - **平条旁小字（★ 文案正式句）**：**「先搁着——没忘。」**（备选：「心搁一搁，等你回来。」）⛔ 语气不带催促、不带惩罚，只作"搁着而已"的一记轻声。替换 UI 现占位「（搁着）」。
5. **满档**：300 ＝ 相许，全亮 ＋「满」。
6. **lv0 显示（★ 已定 · UI 2026-10-03 采纳）**：**档名自 lv1 起才显示**；lv0 头行右只留「{value}/300」；lv0 → lv1 跨越时档名**淡入 200ms**（把"第一次动心"做成一眼可见的瞬间）。⛔ 不在 UI 显「未起」——避开「值>0 却写未起」的语义拧（「未起」仍保留为 `HEART_LV_NAMES[0]` 的数据名，供逻辑与后端使用）。
