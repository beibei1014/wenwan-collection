## 〇、判据 & 一条总则

判据同前两份文档：①称「它 / 这串 / 珠子 / 串儿」②礼物 / 好感 +N 数值 ③保养术语当人格 ④「盘玩 / 挂瓷 / 包浆」当身体状况 ⑤物品化所有格。

> **总则（team-lead 裁定·本轮新增）**：**说话人在物化沁灵 → 保留；旁白或系统在物化沁灵 → 改。**
> 例：主线 9 章里反派（星月 / 坛主）的「还差一颗」「我另取一颗」「一颗珠子，不叫团」= **反派刻意物化，是故事冲突本体，⛔ 绝不改**。
> **实物珠子**一律＝「这串珠子 / 那一串」；沁灵一律＝`ta / 他 / 她 / 名字`，⛔ 不用「它」。

### 1.5 自称数量 / 件数 · 回扫补充（裁定④ · `f_*` 四幕）

> team-lead 裁定④：**说话人是沁灵自己**时，让它亲口说出「凑够数 / 定指标 / 算进一个数」= **自我物化**，比旁白物化更伤 —— 玩家会**直接听见它把自己当件数**。故凡「沁灵自称数量 / 件数」，一律改，落点**落在「人」，⛔ 不落在「数」**。
> 下列 5 条为按此裁定的**回扫补充**（原 §一 表中 f_spring 那条「今年要凑够数」已就地改尾，计入原 66）。

| 文件 | 原文字符串（逐字精确） | 改后字符串 | 物化类型 |
|---|---|---|---|
| js/spirits.js | 🎋 算进一个数 | 🎋 算作自家人 | ①（自我物化·自称个数） |
| js/spirits.js | 我数了一下，今年我们在这儿的有{members}个。去年没这么多。 | 我数了一下，今年我们这儿有{members}位。去年没这么多。 | ①（把同伴计成「个」→「位」） |
| js/spirits.js | 说点新年愿望吧。从我开始 —— 我希望明年群里还能再多几个。 | 说点新年愿望吧。从我开始 —— 我希望明年群里还能再添几个人。 | ①（落点由「数」归「人」） |
| js/spirits.js | 成。那就定个指标。 | 成。那就说定了。 | ①（自称件数）＋现代词「指标」 |
| js/spirits.js | 🧨 定了个指标 | 🧨 家里要添人 | ①（自称件数）＋现代词「指标」 |

> 🔎 回扫范围与判定：已对 `f_new / f_spring / f_trip / f_lost` 四幕逐行过一遍「凑 / 够数 / 还差 / 算我 / 几个 / 数」等关键词。命中「自称数量」的即上表 5 条 ＋ 就地改尾 1 条；其余含「数」字者均**非自称件数**，**保留**：
> - `f_new` `e_warm` 文本「群成员多了{A}」＝成员的**自然计数**（人是人，不是颗数），保留。
> - `f_spring` `e_warm` 文本「后面跟了一串『+1』」＝「一串」指**消息连成串**，非沁灵量词，保留。
> - `f_trip` `e_cool` 结尾名「互相担心的两个」＝**两个人**，自然计数，保留。
> - 主线反派（星月 / 坛主）「还差一颗」「我另取一颗」「一颗珠子，不叫团」「算我的」＝**反派刻意物化 / 玩家自陈**，按总则**保留**（§〇）。
