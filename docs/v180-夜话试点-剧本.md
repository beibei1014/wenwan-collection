## 〇 · 这一批为什么能破掉「每个群聊都一样」

**根因（架构师只读调研）**：`NIGHT_EVENTS` 的剧本只按 `scope`（family / room / duo）过滤 —— 所有 room 群跑同一套 3 条，所有 duo 群跑同一套 2 条，只做 `{A}/{B}/{C}` 名字替换。**同一层里没有任何区分维度。**

**本批的解法（⛔ 零引擎改动）**：

| 层 | 现在 | 本批之后 |
|---|---|---|
| **duo（双人群）** | 只有 1 条 `d_clash`，所有配对都一样 | **＋3 条**，各挂一套**不同的 `when.pers` 性格对** ⇒ 只有那两种性格凑在一处，才开得出那个群。**「这屋和那屋演的不一样」是现成能力**（`duoPick()` 已支持 `when.pers`） |
| **room（同屋群）** | 只有 3 条，每屋都放 | **＋4 条专属剧**（题材全不同），各带 `roomSlot: 0/1/2/3`；引擎侧 `roomSlotOf(thread.id)` 按 roomId **确定性散列**到槽，只放行相符的那 1 条 ⇒ 每个屋都有一条**别人没有的** |
| **family（全家大群）** | 只有「过日子」那一路 | **＋2 条「讲古」**，挂 `after:"a3"` / `after:"a4"` ⇒ 承接序章，**补完主线〈结契篇〉第 1–8 章没交代清楚的背景** |

> 📘**内部说明**：这批是**样板**——把三条路子各走一遍。用户看过调性认可后，按同一套模子往下铺量即可（duo 还有 12 组性格对没用，room 题材还有一堆，family 讲古还能补九域 / 六方势力 / 道脉）。

## 一 · 格式契约（逐字同构现库，⛔ 字段不许自创）

> **落到哪儿（已与架构师对表）**：本批 9 条**⛔ 不塞进 `js/spirits.js` 的 `NIGHT_EVENTS` 本体**——架构师已建好**外部事件合并池**：
> `js/night-v180.js` 里写 `window.NIGHT_V180 = { events: [ …本批事件… ] }`，`index.html` 里**排在 `spirits.js` 之前**加载；引擎载入时把这份外部事件**并进 `NIGHT_EVENT_POOL`**。
> ⇒ **本文件里的 9 个事件对象，就是 `events` 数组的成员**（粘过去即可）。
>
> 照抄 `js/spirits.js:6654–7270` 的 `NIGHT_EVENTS` 写法。

```
{ id, icon, scope:"family"|"room"|"duo", cast:2|3,
  roomSlot:0|1|2|3（仅 scope:"room" 用，见下）,
  star:"newest"|"occasion"（可选）, repeat:"yearly"（可选）, after:"a3"（可选）,
  title, sub, duoTag（duo 专用）,
  when:{ days / members / idle / plays / newFace / occasion / fest / pers / bond / bondLv /
         stage / growth / room / gifted / tixing / isMain / canBreak },   // 只用 WHEN_KEYS 里的键
  nodes:{
    start:{ lines:[{w:"A"|"B"|"C"|"sys", t:"…"}, …], next:"c1" },
    c1:   { lines:[…], choices:[{ t:"玩家选项", go:"m1", tone:"warm"|"cool"|"fun" }, …] },
    m1:   { lines:[…], next:"n2" } 或 { lines:[…], choices:[…] },
    e_warm:{ lines:[…] 或省略, ending:{ key:"warm", name:"…", text:"…" } }
  } }
```

**`roomSlot` 是什么（v180-I1 · 架构师新增 · 只对 `scope:"room"` 生效）**

| 值 | 行为 |
|---|---|
| `0` / `1` / `2` / `3` | 该事件只在这个房间群**被散列到本槽**时放行 |
| **不写**（`undefined` / `null`） | **通用事件** —— 所有房间群都放行（现库 `r_thunder` / `r_joy` / `r_sad` 就是这一类，⛔ 逐字不动） |

> 引擎侧：`roomSlotOf(thread.id) = (散列(thread.id)) % 4` —— **同一个 roomId 永远同一个槽**，无随机、不写存档。
> ⇒ **四条专属剧占满 `0/1/2/3` 四槽**，任一房间群只会看到其中**一条**。✅ 本批四条**已分别标 `roomSlot: 0 / 1 / 2 / 3`**。
> ⚠️ 若主理人日后要加第 5 条 room 专属剧，需要架构师把槽数从 4 扩到 N（**属引擎改动，⛔ 我不动**）。

**硬规矩（本批一律遵守）**

1. `w` 只用 `"A"/"B"/"C"`（主演位）与 `"sys"`（系统提示）；**玩家发言一律走 `choices`**，⛔ 不写 `w:"P"`。
2. `cast:2` 的事件⛔ **不许出现 `w:"C"`**（该位不存在，`thLine()` 会直接丢）。
3. **每条事件必须 3 个结尾**：`e_warm` / `e_cool` / `e_fun`，且**三个都必须走得到**（夜话页明写「每个事件都有 3 个结尾」）。
4. **节点数 = 8**：`start` + `c1` + `m1` + `m2` + `m3` + `e_warm` + `e_cool` + `e_fun`。
   （也可在 `m*` 后再挂一个 `n2` 中转节点，但只要仍收在 8 节点内。）
5. ⛔ **不写死真名**（顾时笙 / 苏栖盏 / 萧景筹 … 一律不出现）——主演一律走 `{A}/{B}/{C}`。
6. ⛔ **不写「主人」**——玩家称谓一律走 `{call}`（自动跟称呼档位走）。
7. 行内引用对白用 **`「」`**，⛔ 不用 ASCII 双引号（JS 字符串本身的双引号除外）。

**可用占位符（`thVars()` 认这些）**

| 类 | 占位符 |
|---|---|
| 玩家 / 群 | `{call}` `{grp}` `{members}` `{total}` `{LIST}` `{days}` `{plays}` `{idle}` `{bond}` `{bondlv}` `{tixing}` |
| 主演（A/B/C 同构） | `{A}` `{B}` `{C}` · `{A_title}` `{A_line}` `{A_trait}` `{A_pers}` `{A_bead}` |
| 首主演 | `{star}` `{star_title}` `{star_line}` `{star_trait}` `{star_bead}` |

> ⚠️ **认不出的占位符会原样留在文案里**（`thText()` 的兜底行为）⇒⛔ 不许自造 `{{xxx}}` 之类的键。上表之外一律不用。

**铁律（世界观层）**：⛔「您」⛔「它」；⛔ 珠子 / 包浆 / 越盘越值钱 / 搁在一边 / 收纳 等物化语域；⛔ 现代 / 西式 / 日式元素。
> 📘**关于「现代元素」的边界（我的判读，请主理人复核）**：夜话的**外壳**本来就是「他们用玩家的手机建群、夜里发消息」——这是**既定设定**（`a1` 原话：「用你手机这件事，是{A}答应的。」），本批**保留外壳、不添新道具**：只用「群 / 消息 / 夜里 / 门口 / 灶 / 铺」这类必要的壳，⛔ 不再引入行李箱、相册、朋友圈之类新现代物；**故事内容（讲古、道脉、结契、掌录者）一律古风、中式**。

## 四 · E 段 · room 群「专属剧」×4 —— 每个屋都有一条别人没有的

> **机制（架构师口径 · v180-I1）**：4 条都是 `scope:"room"`，节点结构一致，**各带 `roomSlot: 0 / 1 / 2 / 3`**；引擎侧 `roomSlotOf(thread.id)` 按 roomId **确定性散列**到槽，只放行相符的那 1 条 ⇒ **同一时刻，每个屋只会开出 4 条里的那 1 条**。
> ⇒ 玩家 A 屋看到「东西不见了」，B 屋看到「谁没回来」——**不再是全屋同一套**。
> **「不同性格组合下的不同走向」怎么落**：room 群的主演是**该屋那两只**（顺序按开沁时间）。所以
> ① 台词按**功能**写（谁先开口 / 谁先把东西收着 / 谁不肯先吃），**谁上来都成立**；
> ② 关键处用 `{A_pers}` / `{B_trait}` 让语言**跟着性格走**；
> ③ 分歧点在 `choices`：玩家的三种处置，**生出三种不同的收场**（`m1/m2/m3` → `e_warm/e_cool/e_fun`）。
> ⛔ `cast:2` ⇒ 全条⛔ 不出现 `w:"C"`；⛔ 不写死真名；用 `{call}`。

| 本批新增 | `roomSlot` | 题材 | 情感钥匙 | `when` |

| `r_lost` | **0** | 屋里有样东西不见了 | 误会 → 体贴 | `{ days: 3, members: 2 }` |
