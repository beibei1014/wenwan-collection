## 〇、三处前置决定

### 0.1 性别人称方案：我选 **B 的零代词变体**

**为什么不是 A（拆成个体句）**：A 会把一句「都睡了」拆成七句，啰嗦，而且**把群体场景拍平成点名**。
**为什么不是原版 B（群体句写「它们」）**：⛔ **「它们」两个字里含「它」**，而硬指标是**全文 0 处「它」**。原版 B 做不到。

**所以我做的是 B 的实质 + 零代词的实现**：

| 场景 | 原版 B（作废） | 本方案 |
|---|---|---|
| 个体 | 它 | **`{ta}` / `{Ta}` / `{ta的}`** |
| 群体 | **它们都睡了** | ⛔ **「都睡了。」**（零指代） |
| 群体发言 | 它们说：… | **「七个声音一起响：…」** |
| 群体·无人应答 | 它们不说话 | **「没人接。」** |

**理由**：
1. **物化的不是「复数」，是「把单只当它」。** 群体句去掉代词，读者读到的是"一群人"，不是"一群东西"。
2. 零指代比「它们」更贴近修仙小说的行文——**修仙小说里写一群人从来不写「他们」，写「众人」「所有人」「没有人」。**
3. 它让硬指标 1（0 处「它」）**可执行**，而不是靠自我说服。

**新增占位符（与 `ps` 标签同形，一条引擎改动）**：
| 占位符 | 渲染 | 例 |
|---|---|---|
| `{ta}` | `boy → 他` / `girl → 她` | 「`{ta}`说：我上。」 |
| `{Ta}` | `他` / `她`（句首，不换字形） | 「`{Ta}`只有一只。」 |
| `{ta的}` | `他的` / `她的` | 「等`{ta的}`那一栏。」 |

⚠️ `rec.gender` 在 `ensureIn`（`:383`）就兜底为 `boy`/`girl`，`born()`（`:398`）挂瓷时掷死，**恒有值** → **⛔ 不需要兜底逻辑**。
⚠️ 人称占位符**不受 `ps` 过滤影响**：一只串不管什么人格，都按自己的性别说话。
