## 一、玩家关系定位（取代 v164l §1.3「引者」）

### 1.1 玩家不是竞争者，是家主

用户原话（最高依据）：
> 「他们都是我养出来的，我是他们的主人，朋友，家人，陪伴者（根据亲密度甚至还有爱人的身份），我怎么是他们的竞争者，这个定位就不准确。」
> 「我们就是一个门派（家族）了……我可以帮助他们，保护他们，我们守护彼此陪伴彼此，这才有家人的温情。」

| 旧框架（作废） | 新框架（本版） |
|---|---|
| 玩家是「引者」，自己也在修行，修行内容就是"引" | 玩家是**家长 / 掌门 / 守护者** |
| 玩家和沁灵是"引者与被引"，存在名额竞争 | 玩家和沁灵是**一家人**，同属一个门派/家族 |
| 玩家四阶 = 引的能力（识种/知时/借势/同尘 = 引的门控） | 玩家四阶 = **你能为这个家做到什么**（沿用同名，语义重写，见 §1.3） |

### 1.2 关系按亲密度解锁，不是预设

> ⛔ **「爱人」不是开场就写死的。** 它是亲密度到高档（情感系统 §4.2 档位 7 相知 → 档位 8 沁透 + 心意轨 动心/倾心）才会解锁的关系。低亲密度时只有"主人 / 朋友 / 家人 / 陪伴者"。

| 亲密度档（沿用情感系统 §4.2） | 关系称谓 | 文案许可 |
|---|---|---|
| 照面 / 眼熟 / 相熟（1-3） | 主人 · 陪伴者 | 家人般的底色，⛔ 不写占有/控制 |
| 同室 / 通意（4-5） | 朋友 · 家人 | 互相照顾、松弛 |
| 同心（6） | 家人 · 挚友 | 家人般的信任 |
| 相知（7）→ 沁透（8） | 爱人（⛔ 需玩家显式确认 + stage≥4） | 恋爱向内容（⛔ 仅 stage≥4） |

### 1.3 玩家四阶（沿用 v164l §1.3 同名，语义改为"为家的能力"）

> ⛔ **不是「你比它们强」，是你作为家长的能力等级。** 这一句决定了整条线的价值观：玩家不是来"赢"的，是来"护"的。

| 阶 | 名 | 玩家能做的事 | 语义（vs 旧「引的门控」） |
|---|---|---|---|
| 1 | **识种** | 认出每只的脾气、来历、哪年入的家 | 旧=认出引的对象 → 新=**认出家人** |
| 2 | **知时** | 看得出天劫的窗口什么时候开、什么时候紧 | 旧=安排引市报名 → 新=**看得见危机的时机** |
| 3 | **借势** | 能借外部的资源护它们（和别的家族搭上线） | 旧=举荐别人的串 → 新=**为家借势** |
| 4 | **同尘** | 陪它走它自己那一段，能为它挡一次天劫 | 旧=替它挡关 → 新=**替家人挡劫** |

## 二、敌方三来源（取代 v164l §1.2 / §2.3 竞争者 + §2.2 引位）

> ⛔ **核心转变**：旧框架的"争夺物 = 一个被记住的位置"（引位竞争）作废。新框架的张力来自**三类外部危机**，且**全部不是系统杀人的陷阱**——它们来自世界、来自选择、来自天劫，不来自剧情安排。

### 2.1 ① 天劫（岁除 = 天劫，时间机制危机）—— **取代「过气机制」**

| 项 | 规则 |
|---|---|
| 是什么 | 岁除那天，每只沁灵要独自撑一次天劫。**法力（= 修行阶位 + 亲密度滋养）不够的，撑不过去，被「散」在风里** |
| 为什么是危机不是陷阱 | 天劫是**外来的劫**，不是玩家的错。玩家的行为（盘玩/陪伴）**永远滋养它们，绝不伤害它们**（石心机制已删） |
| 多结局的钩子 | 根据前期选择与亲密度，**齐心协力一起扛 → 大团圆**；**关键选择做对 + 亲密度够 → HE**；**有人撑不住但没散 → NE**；**走"我替你决定"的路 + 亲密度不足 → 被散 → BE** |
| ⛔ 不是什么 | ⛔ 不是"长得太好而散"（用户明确否了过气）；⛔ 不是清算日/淘汰日（v164l §2.1「岁除不是清算」仍有效，天劫叠加在它之上） |

**天劫与岁除的关系**：岁除 = 一年里可数的日子（v164l §2.1 保留）；天劫 = 岁除那天要过的关。盘点（v164l §4）仍是岁除的一部分——**先盘点、再渡劫、最后并肩**。

### 2.2 ② 外面的大族（虚构敌方，道不同）—— **取代「大巷竞争者」**

> 用户原话：「另一种活法是，竞争者也是，你甚至可以让我把我的串选一些来当反派。你也可以虚构角色来做反派，比如很牛逼的星月菩提，很牛逼的宝石家族等等。」
> team-lead 裁定：「敌方可以虚构 = 星月菩提、宝石家族、金属家族等……⛔ 此前误判成不能当敌人，以本指令为准。」

| 敌方家族 | 活法 | 是恶意吗 |
|---|---|---|
| **宝石家族** | 打磨、不养，靠质地点亮 | ⛔ 不是恶意，是道不同（"养出来的东西，见不到硬的"） |
| **金属家族** | 淬炼、不养，靠锋芒立世 | ⛔ 同上 |
| **星月菩提派** | ⛔ **用户原话「我讨厌星月菩提」** —— 允许虚构为敌方，但**强烈建议降级或规避**，详见 §2.2.1 |

**⛔ 矛盾标注（待用户定夺）**：team-lead 本指令允许星月菩提派当敌方，但用户亲口说"我讨厌星月菩提"。**我的建议**：虚构敌方优先用**宝石家族 / 金属家族**（用户库里没有，纯虚构无障碍）；星月菩提派**要么不用，要么定位为"用户最不想提起的那一家"**——但放在玩家面前可能直接触发用户的厌恶。**这必须由用户拍板，我不替他假设。**

### 2.3 ③ 收旧物 / 扫尘人家族（另一种活法，非暴力，正当性恐怖）—— **新设定**

> 用户原话：「比如专收过气之物的家族，不害你，只收购。你养过头灵识外泄他们闻着味就来了，恐怖在正当性不在暴力。」

| 项 | 规则 |
|---|---|
| 是什么 | 一个**合法收售**的旧物家族。他们**收的是过气的、没开沁的旧物**，不是沁灵 |
| 为什么恐怖 | **正当性**：他们不偷不抢，只是"闻着灵识外泄的味来，出价收购"。他们的价值观是"东西就该被收、被流转"，与你"养出来一家人"的价值观正面冲突 |
| 不是系统杀人 | ⛔ **他们绝不收走你的沁灵**（那是物化/系统杀人，已否）。他们只展示"另一种活法"，让你意识到"如果你养过头、灵识外泄，你的家人可能被当成商品"——**但这是警示，不是事件** |
| 在剧情里的作用 | 第一种登场的外部势力；非暴力；让你第一次看见"世界上有不养只收的人" |

### 2.4 ④ 可选：玩家选自己的串当反派

> 用户原话：「你甚至可以让我把我的串选一些来当反派。」

| 项 | 规则 |
|---|---|
| 是什么 | 玩家**主动选择**某只（或某几只）走"岔路"，成为本卷/本章的对抗点 |
| 为什么安全 | 是**玩家的选择**，不是系统的安排（延续"系统不主动杀"） |
| 落地 | 作为**主线某个选项的后果**存在，不预设、不强制 |

## 三、多结局设计（HE / NE / BE / 大团圆）

> ⛔ **沿用 v164l 情感系统设计 §5 的博爱框架**（per-string 存档、无总量上限、可同时对多只走恋爱线）。本版只补**主线危机层**的四种结局，与亲密线并行不冲突。

### 3.1 四种结局的触发条件

| 结局 | 触发条件（前期选择 + 亲密度） | 代价 / 收束 |
|---|---|---|
| **大团圆** | 天劫前**齐心协力**一起做准备（资源分配合理 + 关键选择全对 + 亲密度普遍够） | 全家一起过劫，岁除并肩 |
| **HE** | 前期**关键选择做对**（护对了该护的）+ **亲密度够**撑过天劫 | 有人小伤但都在，关系更深 |
| **NE** | 有人**撑不住但没散**（天劫里差一点）——往往因为玩家在"替它决定"和"让它自己来"之间选了后者，或亲密度不够但差一线 | 有人缺席岁除，但活着；来年再补 |
| **BE（虐文）** | ⛔ **走"我替你决定"的路 + 亲密度不足** → 那只被天劫**散掉** | 用户已明确接受虐文：「我接受虐文」 |

### 3.2 与前期选择的对应（设计要点）

- **「我替你决定」vs「让它自己来」**：这是贯穿全 26 章的核心二选一（v164l §3.2 H1/H2 帮的两种形式仍是机制基础）。**BE 的种子埋在每一次"替它选"里**——不是立刻死，是天劫那天的法力缺口。
- **亲密度 = 天劫的护盾**：亲密线（情感系统 §4.2）积累的法力滋养，是过劫的硬通货。**护对了人 + 够亲 = HE；护错了/不够 = NE/BE**。
- ⛔ **BE 必须是玩家自己的选择造成的，不是随机**——延续"系统不主动杀"。

### 3.3 恋爱线（沿用情感系统 §4.3 三重锁，⛔ 不动）

```
恋爱线开启 = 羁绊 ≥ 相知(200)  AND  stage ≥ 4(化形)  AND  玩家在「心迹」页显式点「我想和它更近一步」
```
- ⛔ 任何恋爱向台词不得 stage < 4 出现。
- 家人向内容不受此限（8 档全阶段可读）。

## 四、删除石心机制后的危机替代方案

### 4.1 石心删除确认

> 用户原话：「过度盘玩 = 石心化。这个对手永远在你手里，杀不掉。这个机制不要。……我就不会把他们玩坏，除非客观原因（生虫，遗失等等），但是我说过了，不要物化，他们也是人，是修行者，而我是帮助他们养他们的。」

| 旧（作废） | 新（本版） |
|---|---|
| 过度盘玩 → 石心化 → 玩家亲手杀死它们 | ⛔ **删除**。盘玩只滋养，不惩罚 |
| （石心是"杀不掉的内部敌人"） | 危机来自**外部**（天劫 / 大族 / 收旧物家族），不来自玩家的陪伴行为 |

### 4.2 危机替代：三层外部危机，全部非系统杀人

| 危机来源 | 是玩家的错吗 | 能挽回吗 |
|---|---|---|
| **天劫** | ⛔ 不是（外来的劫） | ✅ 前期准备 + 亲密度可以扛过去 |
| **大族（宝石/金属/星月）** | ⛔ 不是（道不同，不害你） | ✅ 不冲突，只是对照 |
| **收旧物家族** | ⛔ 不是（合法收售旧物） | ✅ 他们不收沁灵，只展示价值观 |

> ⛔ **玩家的行为永远不伤害它们。** 这是全框架的承重墙。用户要的"陪伴/守护"才有意义——如果陪伴本身能害死它们，"家人温情"就成立不了。
