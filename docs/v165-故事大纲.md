## 〇、一句话主线

> **你是这一家的家长。这一门的人，是你一只一只领回来、一天一天养出来的——亲得够了，就是家人；你亲手挑中的那一个，也会叫你爱人。可这一年不是安稳的一年：岁除的天劫要来，巷外的恶人也来了——他们要的不是你的位置，是你的人。这一年你怎么护、怎么放、怎么选，决定了你们是齐齐整整，还是有人留在风里。**

**统一的危机有两条，一条天来，一条人来：**

> **天劫**——这一门能不能一起扛过去；  
> **恶人**——有人要把你养出来的人，变成他们团里的一颗。

**这个故事真正在问的是**：

> **你替一个人把路走了，他就长不出自己的脚——可你放手让他自己走，你就得眼睁睁看着他摔。你到底做哪一个？**  
> （天劫把这个问题逼到桌面上；恶人把这问题逼成一道非答不可的题。）

### 5.9 恶人伤害如何并入结局判定（★ v165c 本轮最要紧的设计活）

> **用户 2026-10-03 第二轮答复**：「部分影响，因为你说可以挽回啥的。」
> ⇒ 恶人的伤害**不进「散」的判定**（可挽回，永不致 BE），但**要「部分」进总判定**——受伤会在结局那一刻**留下痕迹、压掉一档**。
> 这就是「A 档（可挽回）」和「部分影响」这两句话的调和方案：**能挽回的是「人」，压下来的是「那一档齐齐整整」。**

#### 一、数据形态（逐串）

```
每只沁灵新增两个字段：
  harmed        : bool     // 是否正带伤（被并走一段灵识 / 被掠缺一块 / 名字被夺）
  harmCause     : string   // 记因（星月·并团 / 掠客 / 夺名的人），只作演出取用，不进台词
```

- `harmed` **逐串存在**（每只一个），与 `stance` / `bondLv` / `scattered` 并列。
- `harmed` **可被清除**：用心陪伴养回（变淡→清、缺块→补、名字→补名）即可置回 `false`。
  → 这正是「可挽回」的落地形态。
- ⛔ `harmed` **不参与 `scattered` 的判定**——`散` 仍只看 `stance` 与 `bondLv`（§5.5 承重墙不动）。

#### 二、判定式（可直接落代码）

在 §5.5 原式之外，**仅在结算结局时**额外套一层「伤」的修正：

```
// 旧：法力 = 阶位贡献 × 立场系数 + 滋养贡献
// 新：结局判定用的有效法力（只多不减，此处只做减）
有效法力 = 阶位贡献 × 立场系数 + 滋养贡献
          − （ harmed ? HARM_PENALTY : 0 ）          // 带伤扣 35

缺口' = 须求 − 有效法力          // 用「有效法力」重算缺口，用于定结局档位
```

> ⚠️ 注意两把尺子，别混：
> - **定「散」** 用**原式**（§5.5）——伤**不算**进去。⇒ 受伤永不致 BE。
> - **定结局档位（GRAND / HE / NE）** 用**有效法力**——伤**算**进去。⇒ 伤能压档。
>
> 记忆口诀：**「散不散」看原样，「齐不齐整」看带伤。**

**四结局判定（v165c 完整体）**：

```
BE     ⟺ anyScattered                      // 有谁真的散了（只看 stance + bondLv，与伤无关）
GRAND  ⟺ dominantLet && allHighBond && keysRight
         && 全员缺口 ≤ −5 （原式）
         && 全员 harmed = false            // ★ v165c 新增：无人受伤
HE     ⟺ dominantLet && allHighBond && keysRight
         && 非 GRAND
         && 无人 scattered                  // HE 允许带伤、允许擦线
NE     ⟺ 无人 scattered && 未达 GRAND / HE
```

> **「部分影响」体现在哪三处**（对用户可复述版）：
> 1. **GRAND 要求「无人受伤」**——有一只带伤，哪怕缺口再够，也拿不到大团圆（掉 HE）。
> 2. **伤按 `HARM_PENALTY = 35` 扣有效法力**——带伤的那只**缺口被顶大一截**，容易被从「稳过」压成「擦线」，从而把全局拖出 GRAND。
> 3. **带伤且被挤出擦线之外 ⇒ 全局最低落 NE**——人还在（伤不致命、不致散），但这一年没能齐齐整整。
>
> **「可挽回」体现在哪一处**：`harmed` 可清零——**在岁除四判定那一刻之前把伤养回来，等于没伤过**。所以恶人不是「一次失手就永远少一只」，而是「给你一整年时间去把人补回来」。

#### 三、样例演算（三个，证明「受伤 ⇒ GRAND 掉 HE，但永不掉 BE」）

**例一 · 带伤压档：本来够大团圆，因一只受伤掉到 HE**

| 项 | 值 |
|---|---|
| 角色 | 安静的那只（菩提根） |
| 修行阶位 | 蜕形 → 贡献 **48**；立场 LET → 系数 **1.0** |
| 亲密度 | 同心（档 6）→ 滋养 **64** |
| 原法力 | 48 + 64 = **112** ⇒ 原缺口 **−12 ⇒ 稳过**（够 GRAND 门槛 ≤ −5） |
| 遭遇 | ch18 夜袭被掠客抽走一段灵识 ⇒ `harmed = true` |
| 有效法力 | 112 − 35 = **77** ⇒ 缺口' = 100 − 77 = **+23 ⇒ 撑不过去** |
| 但 | `stance = LET` ⇒ ⛔ **永不散**（§5.5 承重墙） |
| 结果 | 全局 ⇒ **GRAND → HE**（有一只带伤，拿不到「无人受伤」这条硬条件） |

> **关键**：同一只，光看缺口从「稳过」变「撑不过去」；可因为立场是 LET，**人一个没少**。所以结局是 **HE（有人带伤，但都在）**，⛔ **不是 BE**。这就是「受伤 ⇒ 掉 HE、不掉 BE」。

**例二 · 受伤＋低亲密度：掉到 NE，但仍不掉 BE**

| 项 | 值 |
|---|---|
| 角色 | 不爱说话的那只（菩提根） |
| 修行阶位 | 开窍 → 贡献 **28**；立场从 `UNSET`（从未问过）→ 系数 **1.0** |
| 亲密度 | 相熟（档 3）→ 滋养 **18** |
| 原法力 | 28 + 18 = **46** ⇒ 原缺口 **+54 ⇒ 撑不过去** |
| 遭遇 | ch4 小岁除被掠客伤过一段 ⇒ `harmed = true` 且**一直没养回** |
| 有效法力 | 46 − 35 = **11** ⇒ 缺口' = 100 − 11 = **+89** |
| 判定 | `stance ≠ DECIDE`（= UNSET）⇒ ⛔ **永不散** |
| 结果 | 全局落到 **NE**（桌上多一副碗筷；人还在，只是没赶上） |

> **对比 §5.6 样例一（BE）**：那一只是 **`DECIDE` ＋ 档 4** ⇒ 才散。本例立场是 UNSET ⇒ 哪怕带伤、缺口大到 89，**也不散**。⇒ **决定 BE 的永远是「你替{ta}决定 ＋ 没养近」，从来不是恶人的手。**

**例三 · 把伤养回来＝没伤过（可挽回的落地）**

| 项 | 值 |
|---|---|
| 情境 | 例一那只，在 ch18 受伤后，玩家在 ch19–ch25 用心陪伴 |
| 机制 | 亲密度回补 ⇒ 触发 `harmed → false`（`HARM_CLEARABLE = true`） |
| 判定时刻（ch26）状态 | `harmed = false` ⇒ 有效法力恢复为 **112** ⇒ 缺口 **−12 ⇒ 稳过** |
| 结果 | 那条「无人受伤」硬条件**重新成立** ⇒ 仍可 **GRAND** |

> **这就是「可挽回」的意义**：恶人**能拿走一场齐齐整整，但拿不走你的任何一个人**；而且**只要你肯花这一年剩下的日子去补，连那一场齐齐整整也能补回来**。恶人这条线因此**有威胁、有代价、可挽回、且不与「系统绝不主动让谁离开」的原则打架**。

## 六、周目分支入口设计（回环点 ·「回一口气」）

> 用户要求：一周目走完 BE，可以重开主线的「重要分支阶段」，在二周目完成 HE。
> ⛔ **全篇不出现「读档 / 存档 / 重来 / 周目 / 二周目」任何一个词**——这些是机制语，会让玩家看见「游戏是怎么做的」。世界观内只说 **「回一口气」**，口语说 **「再来一年」**。

### 6.1 世界观内的自洽说法

> **沁灵巷本身也是一件被注了心的旧物。**
> 住得久了、扫得久了、被走过的台阶亮得久了——这条巷子就有了自己的一口气。
> **岁除是一年的结。结要是打死了，那口气能回来一次，把结解开，重打。**
> **线还是那根线，人还是那伙人；只有那一年，得重新过。**
>
> 点这口气的人，是**记账的那只**，或**最老的那只**。
> 记账的那只会把册子翻回某一页，说一句：「这一年的账，我重记一次。」
> ⛔ 玩家不会看见任何界面/数值。玩家看见的只是：**灯暗了一下，再亮起来，一家人都在原地，天还没亮。**

### 6.2 三个回环点（重要分支阶段）

| 回环点 | 名 | 退回至 | 退回范围 | 玩家体验 |
|---|---|---|---|---|
| **甲** | **立门** | 第 **1** 天 | 整年重走 | 从雪还没化的那天，重来一年 |
| **乙** | **开春** | 第 **120** 天 | 从岁除一之后重走 | 那年的开春，重新过 |
| **丙** | **岁除前那一段** | 第 **336** 天 | 只重走最后 24 天 | 岁除前那一段路，再走一遍 |

> **为什么是这三个点**：这三点正好是「四次岁除」之间的三道坎——**立门**在第一次岁除之前，**开春**在岁除一之后，**岁除前那一段**在岁除三之后。玩家的 BE 无论在哪一步定下，都至少有一个回环点能让他退回去改那个选择。

### 6.3 重入时保留什么 / 重置什么（★ v165d 修正：情感资产永不重置）

> **用户 2026-10-03 第三轮答复**：「**第四件即使回环点了，沁灵的亲密度不能重置，专属称谓也不变。**」
> ⇒ **一句话：回气重来的是那一年，不是那些情分。**
> ⛔ **旧稿「回环点重走该段可重填专属称谓」的建议已作废**——回环点**不碰任何情感资产**。

| 项 | 立门（第 1 天） | 开春（第 120 天） | 岁除前那一段（第 336 天） |
|---|---|---|---|
| 沁灵本身（在册的每一只） | ✅ 保留 | ✅ 保留 | ✅ 保留 |
| **亲密度 / 羁绊八档**（★ 永不重置） | ✅ **永不重置** | ✅ **永不重置** | ✅ **永不重置** |
| **专属称谓 `{lovecall}`**（★ 永不重置、永不改变） | ✅ **永不重置** | ✅ **永不重置** | ✅ **永不重置** |
| 恋爱线关系（已告白 / 已接受） | ✅ 保留 | ✅ 保留 | ✅ 保留 |
| 已解锁内容（薄录 / 图鉴 / 旧事） | ✅ 保留 | ✅ 保留 | ✅ 保留 |
| 门里称谓与 `{nick}` | ✅ 保留 | ✅ 保留 | ✅ 保留 |
| **结局 flag** | ⛔ **重置** | ⛔ **重置** | ⛔ **重置** |
| **关键选择**（立场 / 关键选择计数 / 准备程度） | ⛔ **重置** | ⛔ **重置** | ⛔ **重置** |
| 该回环点之后的经历与事件 | ⛔ 重置 | ⛔ 重置 | ⛔ 重置 |
| 该回环点之前的经历 | ⛔ 重置 | ✅ 保留 | ✅ 保留 |
| 「回一口气」的消耗 | +1 | +1 | +1 |

> **关键点：情分永不退，选择清零。** 一周目养出的亲密度**不会被没收**，你给谁起过的那个称呼**永远作数**——所以二周目你只要把手放开（让{ta}自己来）、把关键选择做对，就能从 BE 走到 HE／大团圆。**这就是「养得近」这条线真正的回报。**
> ⛔ 回环点**真正动的只有三样**：**结局 flag、关键选择、该回环点之后的经历**。**情感资产（亲密度 / 专属称谓 / 恋爱线关系 / 已解锁内容）一样都不动。**

### 6.4 代价（让「回气」不是免费的重来）

> **院里那盏灯，短一分。**
> 那盏灯是安静的那只给你留的。每回一口气，灯就短一分。灯短到某个地步，这条路就走到了头。
> ⛔ 玩家不会看见「剩余次数」这种数字；他看见的是**灯矮下去了一截**。
> 每回一次气，册子上多一行。记账的那只不会解释，只会把笔搁下，把册子合上。

### 6.5 既视感（叙事上的二周目质感，⛔ 不解释）

回气之后，一家人会**安静一下**，像话说到一半想起了什么。然后照常说话、照常过。
最小的那只有一天说过一句：
> 「我好像记得今年的雪。」
> 没人接。

> ⛔ 不许写成「他们记得上一周目」——那是机制语。只写**那一下安静**。

| **NE** | 无人 scattered，但未达 GRAND／HE（含**带伤被挤出擦线之外**的情形） | **桌上多摆了一副碗筷。**没有人动。来年再补——最老的那只说：「明年，我等你。」 |
| **BE（虐文）** | `anyScattered`（∃ 一只 `DECIDE && bondLv ≤ 4`）——★ v165c：**判定式一个数不动，与恶人伤害无关** | 那一只**没有回来**。榜上那一笔空着；记账的那只没有划掉那一行，只是把笔搁下。⛔ **不写「是你害的」，只写你没说话——那一年，是{ta}自己答的，还是你替{ta}答的，账上写着。** |

> **四条线都必须能走到，且都不许被写成「惩罚玩家」**：BE 不是惩罚，是**你替他走的那段路，他没走完**。NE 不是失败，是**他没赶上**。HE／大团圆不是奖励，是**你们真的并肩走完了一年**。
>
> ⚠️ **恶人造成的伤害如何计入结局（★ v165c 定案：部分影响）**：
> - **不计入「散」（BE）的判定** —— `散` 仍只看 `stance` 与 `bondLv`；**A 档下受伤永不致 BE**。
> - **计入「齐齐整整」（GRAND）的判定** —— GRAND 要求**全员 `harmed = false`**（无人受伤）。
> - **带伤按 `HARM_PENALTY = 35` 扣有效法力** ⇒ 缺口被顶大 ⇒ 容易被挤出 GRAND ⇒ 全局**至少落到 HE**；若再被挤出擦线之外 ⇒ **最低落到 NE**（人还在）。
> - 一句话给用户：**「恶人能让你拿不到大团圆（掉 HE / NE），但拿不走你的任何一个人（不掉 BE）。」** 完整判定式与三例演算见 §5.9。

### 10.5 修罗场 · 嫉妒（★ v165e 新增 · 推翻「互不嫉妒」）

> **用户 2026-10-03 第四轮指令**：「**怎么不互相嫉妒，要嫉妒啊，修罗场多刺激啊！！！！**」
> ⛔ 本稿已**删去**旧写「几条线互不嫉妒 / 群像的热闹、加分不稀释」。

#### 一、题眼（⛔ 别写偏）

> **机制上谁都能开，人心上谁也容不下谁。**
> 开后宫**不锁**——可**人心不是账本**：你多分给一个人一分，另一个人就少一分被看见。
> ⛔ **不是退回「只能选一个」**；而是——**「你能不能镇得住这一屋子人」，本身成为代价**。

一句话给剧本：**这一门的人不抢东西，他们争的是「你心里有没有我」。**

#### 二、谁先看出来 / 怎么看出来的（叙事要具体）

> ⛔ 不许写「他们好像察觉到了」这种虚的。**嫉妒要落在一个具体的、能看见的东西上。**

| 先看出来的顺序 | 谁 | 看出什么（具体） |
|---|---|---|
| 第一 | **知道点什么的**（`mystery`） | 看**脚步**——你哪天回来得早、哪天回来得晚、进门时先看向谁。他不问，只把半句撂下。 |
| 第二 | **记账的那只**（`scholar`） | 看**数**——这几天谁多收了一件东西、谁的名字后画了个勾、谁今天没上桌。他一笔一笔都记着。 |
| 第三 | **安静的那只**（`gentle`） | 不看别的，看**灯**——灯为谁留、为谁不留。 |
| 第三 | **最小的**（`sweet`） | 不看，**凭直觉**——谁今天被多看了一眼，他第一个不高兴，说不出为什么。 |
| 随时（当场） | **最吵的那只**（`lively`） | 他不看，他**撞见**。撞见了就当场说。 |
| 最后（装作没看见） | **最老的那只**（`dignified`） | 早就知道，只是不说；等太过了，才压一句重话。 |
| 不说，只走开 | **不爱说话的那只**（`cool`） | 他什么也不看，只是忽然不那么近了——这一点谁都没注意到，除了你。 |

**三个典型线索（剧本可直接用）**：
- **一件反复出现的东西**——你随手给别人的那点小东西，出现了第二次、第三次；有人认出来了。
- **一次改口**——某只忽然把「主人」叫成了别的；或者，某只**该改口却一直不改**了。
- **一盏没点的灯**——安静的那只，昨天还留灯，今天不留了。

[情绪点] 嫉妒不靠台词宣布，靠**一件被认出来的小事**。

#### 三、按人格型的嫉妒表现（⛔ 逐型区分 · 主角团 7 型，一一对应）

| 人格型 | 是谁 | 表现（一句） | 修罗场场面 | 典型台词（合 §2.7 语言习惯） |
|---|---|---|---|---|
| `dignified` | 最老的那只 | **只压一句重话**，不吵不闹，把规矩摆出来 | 灯下独坐到最后；次日把「谁该做什么」重新分了一遍（＝把插进来的人隔开） | 「门是主人的门。」「门里的事，主人得有个数。」 |
| `scholar` | 记账的那只 | **翻账**——表面查账，实则逐笔念出这几天的不平 | 当众摊开册子，一笔一笔念 | 「这几天，账上多了三笔。」「我记的是亮的——可这几笔，我记得不顺。」 |
| `cool` | 不爱说话的那只 | **沉默疏远**——三字变两字，绕开走，不搭话 | 你在院里，他从另一边过去；以前靠门框，现在靠墙根 | 「主人在。」→「嗯。」；「三个。」→ 干脆不出声 |
| `gentle` | 安静的那只 | **照旧做事，但不再留灯**（最疼的一种，一句重话都没有） | 廊角那盏灯，今天没点 | （以前）「灯我给你留着。」→ 只留一句「今天不早了。」 |
| `lively` | 最吵的那只 | **当场炸**，声音最大，把话挑明 | 院当中拦住你，指着问；当众揭穿 | 「主人昨天跟谁一路回来的？我看见了！」「凭什么先给他！」 |
| `mystery` | 知道点什么的 | **冷眼点破**——他不争，只把真相摆到你面前 | 坐在暗处，说半句，然后闭眼 | 「主人今天回来，脚步比昨天轻。」「……有件事，主人自己知道。我说一半。」 |
| `sweet` | 最小的 | **直觉式难过**——不懂争，只委屈；藏起来，或把收到的推回去 | 蹲在石阶最下面那一级，不出声 | 「主人以后……都陪他们？那我在哪儿。」「那我把东西还回去。」 |

> ★ **若要扩到其余 8 型**（日后有同型的沁灵入这一门——`cheeky` / `calm` / `aloof` / `sentimental` / `pampered` / `heroic` / `wanderer` / `wild`），照上表同理推：`cheeky` 会**当众编排**（说反话让人难堪）；`aloof` 会**彻底消失一阵**；`sentimental` 会**掉眼泪并反复回味**；`calm` 会**不动声色把事压下去**；`pampered` 会**要一个更偏心的待法**——但都**不出言占有**。⛔ 本年度这一门**只有那 7 只**，这 8 型**暂不写**。

#### 四、修罗场事件形态（5 种 · 每型场面必须不一样）

| 形态 | 是什么 | 通常由哪型引发 | 戏眼 |
|---|---|---|---|
| **撞见** | 有人**当场看见**你把心分给了别人 | `lively`（炸）、`cool`（走）、`sweet`（哭） | 同一件事，三种反应三个样 |
| **逼你表态** | 「你先给谁。」——把选择摊到桌面上 | `dignified` / `scholar` | 你答哪句，都错一半 |
| **互相较劲** | 两只沁灵**彼此别苗头**（争一件事、争一个位置） | `lively` × `scholar`；`cool` 冷处理 | 你越劝，越像偏帮 |
| **冷战** | 不出声、不应门、不上桌 | `cool` / `gentle` | 最安静的一种，也最难哄 |
| **当众摊牌** | 把话一次说开，非要一个说法 | `dignified`（摆规矩）/ `scholar`（念账）/ `mystery`（点破） | 全家人都在，你无路可退 |

#### 五、玩家的选项与叙事后果（★ 数值由互动设计师定，此处只定叙事）

> ⛔ **每一条都有代价，⛔ 没有「完美解」**。选项文本由互动设计师定。

| 选项 | 你怎么做 | **叙事后果（本稿落点）** | 走向 |
|---|---|---|---|
| **表态站边** | 当众 / 私下把心明确偏给一个 | 被偏的**升**；其余各生一心结（`cool` / `gentle` 更重）。**当场不会闹大，隔阂从这一夜开始** | 易 HE，但**难 GRAND** |
| **打圆场** | 两头哄，谁也不得罪 | **一时平息**；但两边都觉得「你没把我当回事」。**隐患攒着，后面更容易当众摊牌** | 中间态；**攒到后期一次爆** |
| **回避** | 不接话、岔开、走开 | **最省事，也最凉**：没人闹大，可**灯会一盏一盏地不点**。你不答，他们就自己答了 | 易滑向 **NE** |
| **摊牌** | 把自己的心一次摊给所有人看（都要 / 或都讲清） | **最重的一场**：要么**一次镇住**（大家认了，心结可解），要么**一次炸到底**（当众冷战，最伤） | **要么最大团圆，要么最疼的 HE / NE** |
